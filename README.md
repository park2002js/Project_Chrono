# Project_Chrono

DKU 2026 캡스톤 디자인 작품. 고정된 검으로 싸우며, 시간을 멈춰 선을 그리는 **Draw**와 그 선을 따라 베는 **Slash**를 사용하는 싱글 플레이 보스 러시다. 데모는 경비 로봇의 공격 패턴 여섯 가지(패턴 2~7)와 처치 후 엔딩까지 담고 있다. [게임 사양](docs/GAME_SPEC.md) · [개발 작업 규칙](AGENTS.md)

## 실행과 조작

Unity Hub에서 [project](project/)를 열고 Unity **6000.3.21f1**을 사용한다. [Title 씬](project/Assets/Scenes/Title.unity)에서 Play를 누른 뒤 **시작 → 저장 슬롯**을 선택하면 [MainWorld 씬](project/Assets/Scenes/MainWorld.unity)으로 이동한다. 새 게임은 시작 통로에서 깨어나 경비를 처치하고, 출구 위 통로 끝의 어둠의 문으로 들어가면 로딩 화면 뒤에서 최종 보스 맵으로 바뀐다. 최종 보스를 처치하고 위쪽 다리 끝의 빛의 문으로 들어가면 데모 종료 문구 뒤 Title로 돌아간다. 새 게임이 시작할 맵은 [GameSystems 프리팹](project/Assets/Prefabs/Startup/GameSystems.prefab)의 `Stage Manager`에서 `Stage Index`로 고른다. 0은 경비 맵부터 이어지는 정식 흐름이고, 1로 바꾸면 새 게임이 최종 보스 맵의 입구에서 바로 시작한다. 이어하기는 슬롯에 저장된 맵을 따른다. 같은 프리팹에서 기상 연출의 누운 시간과 화면 복귀 시간은 `Tutorial Controller`의 `Wake Hold Seconds`·`Wake Return Seconds`, 맵 전환 로딩의 최소 표시 시간은 `Game Manager`의 `Stage Loading Seconds`, 엔딩의 덮는 색과 문구 색은 `Temp Demo Ending`의 `Fade Color`·`Message Color`로 바꾼다.

| 상황 | 키보드·마우스 |
| --- | --- |

| Draw | Shift로 진입하고 왼쪽 클릭으로 두 점을 찍은 뒤 F로 선을 확정한다. R로 점을 지우거나 Shift로 취소한다. |

편집 원본은 [art/archive](art/archive/)에, 게임에 연결한 파일은 [project/Assets](project/Assets/)에 있다. `Assets/Art/`에 새로 가져온 스프라이트와 Aseprite의 기본값은 16 PPU다. 이후 Inspector에서 수정한 PPU는 재임포트 때 유지된다. 개별 VFX의 원본 PNG는 [텍스처 폴더](docs/reference/sephiria/assets/Assets/Texture2D/)에서 파일명으로 찾을 수 있다. [경비 맵 폴더](art/archive/environment/lab-descent-map/)의 `compose.py`가 [석실 그림](art/archive/environment/stone-room-preview/)의 실험실 색 판·원본색 판을 위아래로 이어 붙여 그림과 벽·구역·지점 값을 만들고 Unity 프로젝트에 넣는다. 실행한 뒤 Unity 메뉴 **Project Chrono > Rebuild Guard Map**으로 맵 프리팹에 반영한다. 색이 바뀌는 구간(`PEEL`·`STAIN`), 어둠의 문의 문턱(`GATE_BASE`), 깨어나는 자리·수정·재도전 위치(`WAKE`·`CRYSTAL`·`RESPAWN`), 시작 통로에서 더 내려갈 수 없는 줄(`START_END`)은 `compose.py` 위쪽의 값에서, 벽은 `layout()`에서 바꾼다. 맵 프리팹의 수정과 체크포인트 위치도 이 값으로 옮겨진다. 경비실의 방 그림을 고칠 때는 석실 폴더의 `compose.py`를 먼저 실행하고, 좌우 개폐 문(`hidden-gate.aseprite`)의 프레임은 같은 폴더의 `door.py`로 다시 만든다. 어둠의 문과 빛의 문은 [석조 문 폴더](art/archive/environment/ancient-gate/)의 `gate.py`가 같은 문틀로 함께 만들며 문틀·속·빛 번짐의 층은 `ancient-gate.aseprite`에 있다. 문을 고친 뒤에는 두 맵의 `compose.py`를 다시 실행한다. ### 공격 예고 VFX 사용법

| 공격 범위 | 마스크 사용법 |
| --- | --- |
| 양 끝이 열린 직선 경로 | `열린경로-측선` 두 개를 진행 방향과 평행하게 놓고 그 사이를 `공통-채움`으로 채운다. 측선 폭은 1px이며, 1×5px 마스크의 가운데만 늘린다. 선과 채움 모두 끝에서 첫 픽셀은 투명, 둘째는 절반 농도, 셋째부터 기본 농도다. 예를 들어 80px 경로는 양 끝 2px씩과 가운데 76px로 구성한다. |
| 닫힌 사각형 | `사각-9슬라이스`의 상하좌우 테두리를 1px로 설정한다. 모서리는 그대로 두고 변은 길이 방향으로, 중앙은 가로·세로로 늘린다. Unity Sprite Editor의 Border 값은 네 방향 모두 1이다. |
| 원·타원 | 원하는 지름 또는 가로·세로 크기로 픽셀 격자를 잡고 도형 안쪽을 채운다. 경계 안쪽 한 겹은 1px 테두리로 처리한다. 미리보기의 원은 48×48px, 타원은 64×32px다. |
| 부채꼴 | `부채-반원채움`과 `부채-반원호`의 왼쪽 변 중앙을 공격 시작점에 맞춘다. 이를 좌우 대칭으로 배치하고 조준 방향 양쪽에 중심각의 절반씩 표시한다. 반지름을 바꾸면 최종 격자에서 원호와 양쪽 직선 경계를 1px로 잡는다. |

**색과 투명도.** 흰 마스크에 적대 예고색 **`#FF1559`**(RGB 255, 21, 89)를 입힌다. 한 곳에서 색을 지정하면 `RGBA(255, 21, 89, 168)`을 쓰고 나머지 재질 알파는 100%로 둔다. 그러면 원본 알파가 255인 테두리는 **약 66%**, 128인 내부는 **약 33%**로 보인다. 색과 재질을 따로 제어할 때는 색 알파 225/255와 재질 알파 190/255를 각각 한 번 적용하면 같은 농도가 나온다.

**재생 순서.** 예고A에서 경로를 표시한다. 예고B에서는 같은 경로를 점멸시키고 공격이 임박할수록 점멸과 비프음 간격을 줄인다. 예고C에서는 공격 순간부터 경로를 진동시키고, 그 경로의 마지막 탄환이나 위험이 완전히 지나간 뒤 기본 0.2초에 걸쳐 지운다. 피해 판정은 공격이 담당한다. [공격 예고 사양](docs/GAME_SPEC.md#공격-예고-f-b06)

**Unity에서의 사용.** [공격 예고 프리팹](project/Assets/Prefabs/Enemy/Warnings/AttackWarning.prefab)의 `AreaWarningVfx`가 `Warning Color`(기본 `#FF1559A8`)를 흰 마스크에 입힌다. 공격 코드는 `ShowOpenPath`·`ShowRectangle`·`ShowEllipse`·`ShowSector` 중 하나로 범위를 놓고 `BeginNotice`(예고A) → `BeginImminent`(예고B) → `BeginDanger`(예고C) → `EndDanger` 순서로 부른다. 열린 경로와 닫힌 사각형은 위 마스크를 9분할로 늘리고, 타원과 부채꼴은 최종 픽셀 격자에서 1px 테두리를 다시 계산한다. 예고는 실험실 바닥 레이어보다 위, 캐릭터보다 아래인 정렬 순서 12~13에 그린다.
