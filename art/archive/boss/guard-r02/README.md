# 경비 로봇 정면 R02

**이전 시안:** 현재는 사이렌 제거·총구 높이를 수정한 [R03](../guard-r03/README.md)을 사용한다.

2026-11-16 사용자 수정 요청을 반영한 Aseprite 정면 시안이다.

- [편집 원본](aseprite/01-guard-robot-front.aseprite)

- [로봇 크기 비교](../robots-r02/comparison.png)

검정·흰색 경찰 장갑과 머리 위 빨간 사이렌으로 변경했다. 어깨 수정은 고리/받침 없이 장갑에서 드러나며, 복부에는 길이·테두리·어두운 내부가 보이는 총구5개를 배치했다. 하단 고정축을 제거하고 바닥에 붙는 긴 수평 밑면으로 정리했다.

분리 주먹은 왼쪽 손등이 왼쪽, 오른쪽 손등이 오른쪽을 향하도록 그렸다. 수정은 그 바깥 손등 면에 일부만 노출되며 손가락과 접힌 엄지는 안쪽에 보인다.

| 비교 기준 | R01 | R02 |
| --- | --- | --- |
| 몸통 장갑의 실제 경계 | 61×44px | 92×66px |
| 머리·사이렌·어깨 수정 포함 상체 | 61×58px | 92×87px |
| 각 주먹 높이 | 고리 제외23px | 40px |
| 현재 Player 셀 높이 | 20px | 20px |

몸체는 양축1.5배에 맞춰 다시 그렸고, 주먹은 높이를 Player의2배로 잡았다. 캔버스는192×120px다. 단순 확대 이미지가 아니라 늘어난 해상도에서 총구·손·장갑을 다시 그린1프레임/7레이어 원본이다.

기존 R01과 다른 보스 원본은 보존했다. 이 시안의 최종 미술 선택·다른7방향·애니메이션·Unity 연결은 별도이며, 현재 기준은 [GAME_SPEC3.3.12](../../../../docs/GAME_SPEC.md#3312-보스-6종-탑다운-정면-시안--front-r01)을 따른다.

검증: 전체 실체178×87px,7레이어·18색, 각 주먹34×40px 및5개 총구를 확인했다. native 재열기/PNG 차이0, 중간 알파0, 캔버스 가장자리 접촉0이다.
