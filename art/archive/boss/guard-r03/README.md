# 경비 로봇 정면 R03

**이전 수정본:** 손가락을 각 손 3개+엄지 1개로 정리한 [R04](../guard-r04/README.md)가 현행이다. R03의 사이렌 제거와 총구 수정은 R04에도 유지했다.

2026-11-16 후속 요청에 따라 머리 위 빨간 사이렌을 받침과 함께 제거하고 총구 앞부분을2px 올렸다.

총구의 뒤 장착부는 그대로 두고 앞 입구 중심을 y88→86으로 옮기면서 관을2px 짧게 연결했다.5개의 입구와 가로 위치를 유지했다. 몸통·머리·어깨 수정·양손5레이어는 R02와 픽셀 차이0이며 주먹 높이40px·몸통92×66px도 유지한다.

캔버스192×120px, 실제 불투명 경계178×78px,6레이어·13색·정면1장이다. 원본 재열기/PNG 차이0·중간 알파0·가장자리 잘림 없음·사이렌 색상 잔존0을 확인했다. 기존 R02 native와 PNG의 SHA256도 보존했다.

다른 방향·애니메이션·Unity 연결은 이번 변경에 포함되지 않는다.
