# 경비 로봇 정면 R04

사용자 요청에 따라 양손을 **손가락 3개 + 엄지 1개**로 수정했다. 넓은 흰 손가락 면 사이에 가로 틈을 두 개만 두고, 엄지는 몸체를 향한 안쪽 가장자리에 따로 표현했다. 손등의 보라색 수정은 바깥쪽에 유지했다.

- 편집 원본: `aseprite/01-guard-robot-front.aseprite`
- 투명 PNG: `png/01-guard-robot-front.png`
- 전체 확인: `preview-6x.png`
- 양손 확대 확인: `hand-detail.png`
- 검증 결과: `validation.json`

캔버스는 192×120, 각 손은 기존과 같은 34×40이다. 이전 R03의 손 외곽 알파와 손 이외 네 레이어는 픽셀 단위로 동일하다. 머리 위 빨간 장식 제거와 총구 입구를 2px 높인 R03 수정도 유지했다. Aseprite를 저장 후 다시 열어 PNG와의 픽셀 일치 및 반투명 픽셀 부재를 확인했다. 미리보기에서 세 손가락 면과 안쪽 엄지 한 개를 육안 확인했다. 사용자 디자인 확정 및 Unity 적용은 별도다.
