# 경비 로봇 정면 R05

첨부한 주먹 참고 이미지처럼 넓은 윗면과 어두운 앞면·옆면이 이어지도록 양손의 입체감을 수정했다. 윗면은 첫 번째 손가락과 연결된 9px 깊이의 면이며, 세 손가락 각각에 윗면·앞면·하단 명암을 넣었다. 손가락 사이 검은 주름은 두 줄로 유지하고 안쪽 엄지는 짧게 굽은 덩어리로 표현했다. 바깥 손등에 박힌 보라색 수정도 유지했다.

- 편집 원본: `aseprite/01-guard-robot-front.aseprite`
- 투명 PNG: `png/01-guard-robot-front.png`
- 전체 6배 확대: `preview-6x.png`
- 양손 10배 확대: `hand-detail.png`
- 검증 결과: `validation.json`

캔버스 192×120, 각 손 34×40 및 손 외곽 알파는 R04와 동일하다. 기존 13색을 유지했으며 몸통·머리·총구·어깨 수정의 네 레이어는 픽셀 변화가 없다. 손가락은 3개와 엄지 1개로 유지하고, 저장 후 원본 재개봉·PNG 픽셀 일치·반투명 픽셀 부재를 검사했다. 손 확대를 통해 입체감과 손가락 구분을 별도로 검토했다. 기존 R04는 보존했다. 사용자 디자인 확정 및 Unity 적용은 별도다.
