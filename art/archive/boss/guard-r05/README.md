# 경비 로봇 정면 원본

[Aseprite](aseprite/01-guard-robot-front.aseprite) · [PNG](png/01-guard-robot-front.png)

현재 경비의 몸체·양손 형태를 결정한 정면 원본이다. 실제 게임에서는 [분리 원본](../guard-hand-r01/README.md)의 몸체와 양손 PNG를 사용한다. 같은 원화의 레이어를 보존해 분리했으며 새 픽셀을 그린 것은 아니다.

원본 편집 시 몸체·손의 상대 위치와 피벗을 유지하고 실제 분리 출력에도 반영한다. 전투 동작과5패턴은 [GAME_SPEC](../../../../docs/GAME_SPEC.md)의 F-B07을 따른다.
