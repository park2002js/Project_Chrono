# pattern

1. (튜토 전용 1회 특별 패턴) 양쪽의 총구에서 예고를 한 뒤, 빠르게 이동하는 탄환을 발사 (게임 첫 시작시 Draw & Slash를 알려주는 용도)
→ 예고A가 일어나기전 Draw 튜토가 발생함. Draw에서는 그어야할 선의 방향과, 점의 위치, 등을 모두 알려준다.
→ 예고A의 0.7초 이후 예고B가 0.6초간 발생하고 난 뒤, 발사되는 순간 총알이 특정 지점에서부터 점점 느려짐과 동시에 화면이 탄환을 제외하고 점점 어두워지다가, 선이 그어져 있는 특정 지점에 완전히 멈춰선다.
→ 여기서 Slash 키안내를 하여 Slash 키를 누르도록 유도한다. Slash 키를 누를 시 일반적인 때처럼 Slash 연출이 발생한다.
→ Slash 연출이 끝나면 설명 전용 UI와 함께 하는 것과, 그 Slash를 통해 탄환이 그로기 게이지를 채우는 것과, 황금 탄환은 반사된다는 것을 알려줌.
2. 복부의 좌우에서 플레이어 위치를 향해 빠르게 일직선으로 이동하는 탄환을 발사 
→ 플레이어가 어디에 있든, 플레이어의 위치를 추적하며 0.7초간 예고A를 보여준다.
→ 0.7초의 예고A가 끝나면, 그때의 플레이어 위치에 대해 0.6초동안 예고B를 실행한다.
→ 예고B가 끝나면 예고C가 연출됨과 동시에, 황금색의 빠른 탄환이 양 총구에서 예고B에서 확정지은 위치 지나도록 동시에 발사된다. 
3. 손이 공중에서 플레이어 위치를 추적한 뒤, 예고 후 떨어짐
→ 이 패턴은 Idle 상태에서 계속 진행되어 플레이어가 가만히 서있지 않도록 만든다. 이때에도 패턴들의 쿨타임 타이머는 돌아가며, 다른 패턴이 진행되면 이 공격을 멈춘다. 손을 사용하는 패턴이 아닌 패턴이 시작될 때에는 다시 기본 위치로 양손 모두 이동하며 해당 패턴이 시작되도록 한다.
→ 주먹 공격시, 1초간 플레이어 위치를 추적하며 타원의 예고A를 보여준다.
→ 1초의 예고A가 끝나면, 그때의 플레이어 위치에 대해 0.6초동안 예고B를 실행한다.
→  예고B가 끝나면 smear frame과 함께 아래로 내려찍는 모션을 취한다. 이 모션은 0.06초(60fps기준 2프레임)이동안 발생한다. 이 모션이 끝나야 실제 해당 위치에 피해를 가한다. 
→  위에서 한손이 공격을 했다면, 다른 한손이 공격을 한다.
4. 두 손을 모아 힘을 모은 뒤 중앙을 내려침. 중앙에서 일정 범위에 충격이 가해지며 세로 일렬로 총탄이 양쪽으로 퍼져 나감
→ 힘을 모으는 순간은 두 손이 이동하여 특정 지점에 모였을 때를 기준으로 시작하며, 그 상태에서 1.5초동안  힘을 모으는 VFX가 손이 접해진 부분에서 발생한다.
→ 힘을 다모으면 0.6초간 추락 위치를 중심 타원형 예고B를 생성한다. 
→ 0.6초간의 예고B가 끝나면 smear frame과 함께 아래로 내려찍는 모션을 취한다. 이 모션은 0.06초(60fps기준 2프레임)이동안 발생한다. 이 모션이 끝나야 실제 해당 위치에 피해를 가한다. 
→ 바닥에 내려쳤을 때 충격파가 발생함과 동시에 해당 위치에 피해를 입히며, 바닥을 내리친 순간의 추락 위치를 중심으로 원형으로 2중으로 된 투사체를 지그재그가 되도록 발사한다. 이때 하나의 원 라인을 이루는 투사체의 수는 20개이다.
5. 눈에서 에너지를 모은 뒤 레이저를 발사함. 
→ 플레이어의 위치를 중심으로 특정 거리 내의 무작위 위치에서 레이저가 닿는 시작점으로 삼는다.
→ 시작점에서 플레이어의 위치를 지나는 벡터를 결정한 뒤, 플레이어의 위치를 시작점과 끝점에 대해서 3/4 지점으로 삼도록 길이를 설정한다
→ 그 벡터의 길이를 따라 레이저의 피해를 결정하는 바닥면을 이동시키며, 점점 끝으로 갈수록 이동 속도가 빨라진다.
6. 복부의 좌우 총구에서 부채꼴로 퍼져나가는 탄환을 좌-우-좌-우 순서대로 발사함
→ 두 총구는 동시에 동일하게 총알 발사 준비 이펙트를 시작한다. 이 이펙트는 1.5초간 진행되며 이 전용 SFX가 출력된다.
→ 모든 준비가 완료되면, 0.6초간 양쪽의 총구를 꼭짓점으로 하는 부채꼴의 예고A를 보여준다.
→ 0.6초의 예고 A가 끝나면 부채꼴의 펼쳐진 각도에 맞춰  천천히 이동하며 퍼져나가는 투사체들을 0.6초 단위로 번갈아서 발사한다.투사체는 한번의 발사에 총 8개가 하나의 총구에서 퍼져나간다.
7. 왼손 혹은 오른손이 특정 위치로 이동한 다음 기를 모았다가 땅바닥을 내려쳐 충격파를 내보낸다.
→ 왼손은 왼쪽 끝 위치 어딘가에서, 오른손은 오른쪽 끝 위치 어딘가에서 기를 모으는 VFX와 함께 기를 3.5초간 모은다. 이때 주먹은 공중에 떠있기에 그 떨어질 위치에 그림자가 져있다.
→ 기를 모은 뒤, 주먹 아래의 타원의 예고B와 map 중앙 방향으로의 부채꼴 예고B가 시작되며 0.6초 뒤에 smear frame과 함께 아래로 내려찍는 모션을 취한다. 이 모션은 0.06초(60fps기준 2프레임)이동안 발생하고, 그 뒤에 내려찍힘과 동시에 피해를 주는 로직인 후의 과정이 일어난다. 
→ 주먹이 바닥에 떨어지면 충격파 왜곡 VFX와 흑먼지 VFX, 폭발 VFX 와 함께 타원 부분에 피해가 발생하고, 부채꼴 예고 범위대로 피해를 주는 VFX가 퍼져나가며 피해를 준다.
