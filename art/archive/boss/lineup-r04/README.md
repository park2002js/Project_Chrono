# 최신 보스 5종·Player 동일 배율 비교

**이전 비교판:** 경비 주먹의 입체감을 수정한 [R05 전체 비교](../lineup-r05/README.md)를 현재 검토판으로 사용한다. 나머지 대상의 디자인과 배율은 같다.

[한 장으로 보기](lineup.png) · [편집 가능한 Aseprite](lineup.aseprite) · [배치·검증 기록](manifest.json)

모두 동일한 **3배 최근접 확대**로 배치했다. 하단 기준선은 같으며 개별 크기를 맞추는 확대·축소는 하지 않았다. 그림 아래 픽셀 치수는 투명 여백을 제외한 실제 외곽이다. 연구자와 슈트의 원본 캔버스는 각각 30×30px다.

왼쪽부터 현재 Player의 Idle 첫 프레임, 경비 R04, 군용 R03, 뱀 R04, 슈트 R01, 연구자 R02 흩날림 첫 프레임이다. 꽃은 제외했다.

1920×720px PNG와 대상별 6레이어·배경 1레이어의 Aseprite를 저장했다. 원본 6파일 해시 불변, native/PNG 픽셀 차이 0, 겹침·잘림 없음과 시각 배치를 확인했다. 원본 디자인·Unity 에셋은 변경하지 않았다.
