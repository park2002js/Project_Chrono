# 보스 5종·Player 비교 — 경비 주먹 입체감 수정

**이전 비교판:** 등 수정 제거·두꺼운 몸통의 군용 R02 정면을 반영한 [R06](../lineup-r06/README.md)가 현재 전체 비교다. 나머지 대상은 유지했다.

[전체 그림](lineup.png) · [편집 가능한 Aseprite](lineup.aseprite) · [배치·검증 기록](manifest.json)

경비 주먹의 윗면·옆면과 명암을 보강한 R05를 동일 배율 검토판에 반영했다. 왼쪽부터 Player Idle 첫 프레임, 경비 R05, 군용 R03, 뱀 R04, 슈트 R01, 연구자 R02 흩날림 첫 프레임이다.

모두 동일한 **3배 최근접 확대**이고 하단 기준선도 같다. 그림 아래 픽셀 치수는 투명 여백을 제외한 외곽이며, 연구자와 슈트의 원본 캔버스는 각각 30×30px다. 이전 비교판의 배치와 나머지 원본을 유지했다.

1920×720px PNG와 개별 대상 6레이어·배경 1레이어의 Aseprite를 저장했다. 재열기·native/PNG 픽셀 차이 0·입력 6파일 해시 불변·겹침과 잘림 없음을 확인했다. Unity 적용은 수행하지 않았다.
