# 전투 기계 로봇 OBJ 3D 시안 R01

[OBJ·재질 묶음](military-robot-obj-package.zip) · [OBJ](military-robot.obj) · [MTL](military-robot.mtl) · [회전 미리보기](viewer.html)

[정면·사선 렌더](preview-final.png) · [옆·뒷면 렌더](side-back-preview.png) · [기준 정면](front-reference.png)

사용자 요청에 따라 군용8방향 R02의 정면을 기준으로 실제 입체 메시를 먼저 제작했다. 둥근 두꺼운 몸통, 모서리가 둥근 머리와 붉은3슬릿, 노출된 피스톤 팔, 모래색 어깨/복부 판, 청회색 주먹·밑창과 주먹 수정2개를 반영했다. 등 수정·끈·받침대는 없다. 정면에서 확인할 수 없는 깊이와 후면은 제작 추정이다.

## 파일과 열기

- `military-robot.obj`: 부위 이름으로 구분한60개 메시 객체,7,602정점·14,964삼각형
- `military-robot.mtl`:18개 단색 재질. 외부 텍스처 이미지는 사용하지 않는다. OBJ와 같은 폴더에 둔다
- `viewer.html`: 파일 안에 메시와 재질을 포함한 오프라인 WebGL 미리보기. 드래그로 회전하고 휠로 확대·축소한다
- `model-info.json`: 부품 목록·정면 출처·규격
- `validation.json`: 실제 OBJ를 별도로 다시 읽은 구조 검사

Y축이 위쪽, +Z가 정면이며 발바닥은 Y=0이다. 전체 크기는 가로3.21×높이3.17×깊이1.889의 **임의 모델 단위**다. 실제 게임 배치 크기는 아직 정하지 않았다.

## 확인 범위

내보낸 OBJ와 MTL을 다시 읽어 정면·사선·옆면·뒷면을 렌더링하고 기준 정면과 대조했다. 골반 앞판이 관절에 묻히던 부분과 피스톤/콜라의 같은 높이에서 겹치던 면을 정리했다. 재질 참조, 정점·노멀·인덱스, 퇴화 삼각형, 부품별 닫힌 경계와 방향을 독립 검사했다.

각 부품은 닫힌 메시이지만 조립된 부품끼리의 겹침을 제거한 단일 불리언 메시라는 뜻은 아니다. 부품 간/자기 교차 전수 검사는 수행하지 않았다. Blender 또는 Unity로 실제 import한 결과, 리깅·애니메이션·UV/텍스처 작업은 이번 범위에 포함하지 않는다. 현재 결과는 첫3D 제작안이며 GAME_SPEC3.3.12를 따른다.

회전 미리보기의 실제 브라우저 표시는 이 환경에서 확인하지 못했다. 제공한 PNG 미리보기는 OBJ와 MTL을 직접 읽어 렌더링한 결과다.
