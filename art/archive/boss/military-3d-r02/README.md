# 전투 기계 로봇 3D R02

[OBJ·MTL 묶음](military-robot-obj-package.zip) · [OBJ](military-robot.obj) · [색상 재질 MTL](military-robot.mtl)

[정면·사선](preview-final.png) · [옆·후면](side-back-preview.png)

사용자 후속 요청을 반영해 몸통을 사각 장갑 형태로 바꾸고 등에 다연장 로켓 발사기를 달았다. 양손은 망치나 주먹이 아니라 팔 끝에 연결된 미사일 로켓 발사기다. 보라 수정은 양손 발사기의 바깥쪽 손등 면에 일부 박힌 형태로 배치했다. 국방색과 모래색·청회색 재질, 얼굴의 붉은3슬릿, 피스톤 팔과 다리는 유지했다.

등 발사기의 4×2 배열8관, 양손 각1관, 구체적인 깊이·크기·배치는 이번 제작안이다. 사용자가 발사구 개수나 실제 공격 규칙을 확정한 것으로 보지 않는다. 발사관에는 실제 입구·내벽·깊은 안쪽 면이 있다. 등에 멘 수정은 없다.

## 파일

- `military-robot.obj`: 부위 이름으로 구분한92개 객체,13,348정점·26,328삼각형
- `military-robot.mtl`:18개 색상 재질. OBJ와 같은 폴더에 둔다
- `model-info.json`: 규격과 부품 목록
- `validation.json`: 내보낸 OBJ를 별도 파서로 읽은 구조 검사
- `front-reference.png`: 제작 출발점인 기존2D 정면. 이번 사각 몸체·발사기 수정은 후속 사용자 요청에 따른다

Y축이 위, +Z가 정면, 발바닥은 Y=0이다. 크기는 약4.158×4.411×3.066의 임의 모델 단위이며 실제 게임 크기를 지정한 값은 아니다. 외부 텍스처 이미지는 사용하지 않는다.

## 확인 범위

OBJ와 MTL을 다시 읽어 정면·사선·측면·후방 사선을 렌더링해 확인했다. 재질·정점·인덱스·노멀, 부품별 닫힌 경계와 방향, 좌우 대칭을 독립 검사했다. 이전 R01 파일은 보존했다.

부품은 개별 닫힌 메시로 조립했으며 단일 불리언 메시가 아니다. 자기 교차·부품 간 겹침의 전수 검사는 수행하지 않았다. Blender/Unity 실제 import, 리깅·UV·애니메이션·로켓 공격 구현은 미실행이다. 현재 결과는 형태 검토용 OBJ 시안이며 사용자 최종 미술 승인과 구분한다.
