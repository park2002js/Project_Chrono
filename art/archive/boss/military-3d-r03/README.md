# 전투 기계 로봇 3D R03

[OBJ·MTL 묶음](military-robot-obj-package.zip) · [OBJ](military-robot.obj) · [MTL](military-robot.mtl)

[정면·사선](preview-final.png) · [측면·후면](side-back-preview.png) · [발사구 상세](launcher-details.png)

사용자 요청대로 등 발사기를 통처럼 메는 형태로 바꾸고 발사구를3×3, 총9개로 구성했다. 통의 띠를 포함한 전체 너비2.20은 몸통 너비2.20과 같다. 통은 등에 세워 메며 발사구가 윗면을 향하는 제작 해석이다.

양손 발사기는 각각2개 발사구로 변경했다. 본체 너비는0.82에서0.70으로 약15% 줄이고 앞뒤 두께는1.10에서0.66으로 줄였다. 피스톤 팔·손목·발사기 본체의 X/Z 중심을 일치시켰고 두 발사관은 그 중심 양쪽에 나란히 배치해 팔의 Y축 방향으로 이어진다. 대기 자세에서 발사구는 아래를 향한다. 보라 수정은 바깥 손등 면에 유지했다.

## 파일과 규격

- `military-robot.obj`:82개 이름별 부품,11,538정점·22,756삼각형
- `military-robot.mtl`:18개 색상 재질. OBJ와 같은 폴더에 둔다
- `model-info.json`: 부품 목록·발사구 수·축·규격
- `validation.json`: 독립 OBJ 구조·재질·대칭 검사
- `layout-validation.json`: 기존 R02 보존과 등 폭·구멍 수·팔 정렬의 실제 OBJ 대조
- `front-reference.png`: 초기 제작 기준2D 정면. 이후 형태는 사용자 후속 요청으로 변경했다

Y축이 위, +Z가 정면이며 발바닥은 Y=0이다. 전체 크기는 약3.968×3.420×3.337의 임의 모델 단위다. 외부 텍스처 이미지는 사용하지 않는다.

## 확인 범위

내보낸 OBJ/MTL을 다시 읽어 정면·사선·측면·후방 사선과 발사구 상세를 렌더링했다. 부품별 닫힌 메시·면 방향·인덱스·노멀·재질·좌우 대칭과 기존 R02 보존의 독립 검사를 통과했다. 실제 검사 결과는 검증 JSON을 따른다.

부품을 조립한 모델이며 단일 불리언 메시나 리깅된 모델은 아니다. 자기 교차·부품 간 교차의 전수 검사, Blender/Unity 실제 import·UV·애니메이션·실제 로켓 공격 구현은 미실행이다. 발사구 수·너비 맞춤·팔 정렬은 사용자 요청이며 발사 방향과 통의 세부 깊이·높이는 제작안으로 구분한다.
