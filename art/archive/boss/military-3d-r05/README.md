# 군용 로봇 최종3D 형상 원본

등 런처 박스 폭1.76·몸통 폭2.20,등색`#354333`·몸통색`#74834E`로 두 부분을 구분한다.3×3 원형 발사구·양손 발사기·수정·머리·몸통·다리를 부품별 메시로 구성했다.

OBJ95부품·13,510정점·26,676삼각형과MTL21재질이다. OBJ/MTL은 같은 폴더에 두며Y축이 위,+Z가 정면,발바닥Y=0이다. 단위는 임의 모델 단위다.

이 형상은 [8방향 픽셀 자산](../military-8dir-r04/README.md)의 형태 원본이다. 리깅·UV·3D 애니메이션·전투 보스 구현과 사용자 최종 미술 승인은 별도다.
