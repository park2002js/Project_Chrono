# 전투 기계 로봇 3D R05

[OBJ·MTL 묶음](military-robot-obj-package.zip) · [OBJ](military-robot.obj) · [MTL](military-robot.mtl)

[정면·사선](preview-final.png) · [측면·후면](side-back-preview.png) · [발사구 상세](launcher-details.png)

등 런처를 몸통보다 좁고 짙게 만들어 두 부분을 구분했다. 박스 너비는2.20에서1.76으로20% 줄였고, 몸통은2.20을 유지했다. 박스 기본색은 짙은 국방색 `#354333`, 몸통은 기존 `#74834E`다. 구체적인 축소율과 색상은 사용자 요청에 따른 제작값이다.

사각 박스와3×3 원형 발사구를 유지하면서 가로 간격만 좁혔다. 발사관의 지름은 유지했다. 양손 각2구·팔 축·손등 수정·머리·몸통·다리 등 비등67개 부품은 R04와 동일하다. 기존 R04 파일은 보존했다.

## 파일·확인

- OBJ:95개 부품,13,510정점·26,676삼각형
- MTL:21개 재질. 기존18개를 유지하고 등 전용 짙은 재질3개를 추가했다. OBJ와 같은 폴더에 둔다
- `model-info.json`: 부품 목록·너비·색상
- `validation.json`: OBJ 메시·재질 검사
- `layout-validation.json`: 등 폭·3×3 원형관·색상 구분 검사
- `preservation-validation.json`: R04 원본과 비등 부품 보존 대조

Y축이 위, +Z가 정면, 발바닥은 Y=0이다. 전체 크기는 약3.968×3.420×3.382의 임의 모델 단위다. 내보낸 OBJ/MTL을 다시 읽어4방향과 등/손 상세를 렌더링해 확인했다.

부품별 닫힌 메시로 조립했으며 단일 불리언 모델은 아니다. Blender/Unity 실제 import, 리깅·UV·애니메이션·공격 구현과 부품/자기 교차 전수 검사는 미실행이다. 사용자 최종 미술 승인은 별도다.
