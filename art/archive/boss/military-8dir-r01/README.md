# 전투 기계 로봇 8방향 R01

**사용자가 미술 방향을 반려한 이전 시안:** 과한 입체감과 사각 도형 인상을 수정하고 등 수정·끈·받침대를 없앤 [R02](../military-8dir-r02/README.md)가 현행이다. 아래 내용은 R01의 제작·기술 검사 이력이며 사용자 미술 승인이 아니다.

[8방향 3배 미리보기](preview-final-3x.png) · [Aseprite 원본](aseprite/02-military-robot-8dir.aseprite) · [투명 스프라이트 시트](military-8dir-sheet.png)

기존 군용 로봇 R03 정면을 보존하고 오른쪽 앞(SE), 오른쪽(E), 오른쪽 뒤(NE), 뒤(N) 4방향을 새로 제작했다. 왼쪽 앞·왼쪽·왼쪽 뒤는 대응 방향의 정확한 좌우 반전이다. 걷기 애니메이션이 아닌 방향별 정지 이미지 8장이다.

등 수정은 등에 멘 물체로 표현했다. 윗부분을 검은 끈으로 감싸고, 아래쪽 U자 받침을 등판에 연결했다. 옆·뒤 방향에서는 고정 구조와 수정의 깊이가 드러나며 앞쪽에서는 머리에 일부 가린다. 새 방향의 고정장치 세부 픽셀 배치는 제작안이다.

국방색 장갑·모래색 부품·청회색 주먹과 밑창을 유지했다. 붉은 3슬릿은 머리 앞면, 주먹 수정은 정면 장갑판을 따라 회전하므로 옆·뒤에서 가려진다. 가까운 팔과 먼 팔의 가림 및 발끝 방향을 반영했고 별도 발사장치는 추가하지 않았다.

공통 캔버스는 **112×144px**, 시트는 **896×144px**다. 회전한 발이 잘리지 않도록 하단 여백 8px을 추가했으며 기존 S의 112×136 영역과 위치는 픽셀 그대로 유지했다. Aseprite는 8프레임·14레이어로, S의 기존 10부위 레이어와 새 방향 4레이어를 보관한다. 각 프레임 100ms는 저장 형식상의 값이며 전투 애니메이션 시간으로 확정한 것이 아니다.

[검사 기록](validation-independent.json)에서 8프레임 PNG/native 차이 0, 정면 원본 차이 0·추가 여백 투명, 좌우 3쌍 및 N 대칭 차이 0, 원본 31색 팔레트 외 색 0, 중간 알파 0, 캔버스 가장자리 접촉 0을 확인했다. R03 native·PNG 해시를 보존했고 방향별 시각 검토를 완료했다. [배치 정보](manifest.json)의 방향 순서·원본 경로를 따른다.

이번 결과는 정지 방향 원본·출력이며 Unity 연결이나 이동·공격 모션은 수행하지 않았다. 현행 사양은 GAME_SPEC 3.3.12를 따른다.
