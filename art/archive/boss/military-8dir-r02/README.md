# 전투 기계 로봇 8방향 R02 — 두꺼운 몸체와 그림식 픽셀 표현

[8방향 3배 미리보기](preview-final-3x.png) · [Aseprite 원본](aseprite/02-military-robot-8dir.aseprite) · [투명 시트](military-8dir-sheet.png)

사용자는 R01의 과한 입체감과 사각 도형 인상을 반려하고, 등 수정을 제거하며 몸체를 두껍게 다시 그리도록 요청했다. 정면을 포함한 8방향을 수정했다. 등 수정·검은 끈·받침대는 모두 제거했고 주먹 수정은 유지했다.

새 방향은 3D 면 투영 대신 방향별 2D 픽셀 형태로 그렸다. 둥근 가슴·등 윤곽, 얕은 윗면, 이어지는 올리브색 덩어리와 적은 내부 선으로 표현했다. 국방색·모래색 부품·청회색 장갑, 정면의 붉은 3슬릿은 유지했다. 가까운 팔과 먼 팔의 가림은 남기되 세부 명암을 단순화했다.

[몸통 레이어 측정](torso-metrics.json): R03 정면 몸통66×61px에서 R02 정면78×64px로 폭을12px 늘렸다. R02 옆면 몸통은69×62px다. 이는 몸통 부위의 측정이며 전체 스프라이트 크기와 구분한다.

공통 캔버스112×144px, 정지8프레임·7부위 레이어, 시트896×144px다. 좌우3쌍은 정확한 반전이며 정면·후면도 대칭이다. 프레임당100ms는 저장 형식상의 값으로 이동 모션 시간이 아니다.

[독립 검사](validation-independent.json)에서 PNG/native 차이0·좌우 반전/정후면 대칭 차이0·원본31색 팔레트 외 색0·중간 알파0·경계 접촉0·위쪽 수정 색상0을 확인했다. 등 장식 제거·명암 덩어리·몸체 두께·SE/SW 시선 방향은 확대 시각 검토했다. 기존 R03/R01 원본 파일은 보존했으며, R02의 정면 그림 자체는 이번 요청으로 수정됐다.
