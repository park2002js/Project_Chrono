사용자가 긍정 승인한 [3D R05](../military-3d-r05/README.md)의 실제 OBJ를 같은 조건으로 회전 투영해 픽셀화했다. 좁고 짙은 사각 등3×3 런처, 사각 몸통, 양손 각2구와 바깥 손등 수정, 국방색·모래색·청회색 구분을 유지했다.

## 대각선 구도와 규격

모든 방향에 **정사영·고도30°·모델 단위당27px·지면 피벗(72,120)**을 적용했다. 방향별 확대/축소, 가로세로 비균등 변형이나 자동 프레이밍을 사용하지 않았다. 대각선의 면 너비와 부품 가림은 같은 모델을45°씩 돌린 투영 결과다. 방향별 외곽 크기는 달라져도 배율과 지면 기준은 같다.

- 각 PNG/프레임:144×144px, 투명 배경, 알파0/255
- 팔레트:29색의 고정 색상 단계 중 실제24색 사용, 안티앨리어싱·디더링 없음
- Aseprite:8개 정지 방향 프레임,7개 부위/윤곽 레이어,8개 방향 태그
- 시트:1152×144px, 아래 순서로 가로 배치
- 저장상 프레임 시간100ms는 이동 모션 시간이 아니다. GIF는 방향 확인용500ms 전환이다
- 부위 레이어는 각 방향에서 실제로 보이는 픽셀을 분리한 것이며 가려진 뒷부분을 복원한 레이어가 아니다

## 확인 범위

[구성/투영 정보](manifest.json), [독립 native 검사](validation-independent.json), [카메라·팔레트·보존 검사](camera-palette-validation.json)를 제공한다. Aseprite를 다시 열어8개 프레임을 PNG로 출력하고 원본과 픽셀 차이0을 확인했다. 해상도·태그·팔레트·알파·최소6px 여백, 공통 카메라/피벗과 모델 투영을 검사했다. 확대 비교와 승인 모델 대조에서 대각선 비율·방향·부품 가림을 확인했으며 기존3D R05와 픽셀 R02의35개 산출물을 보존했다.

이번 결과는8방향 정지 스프라이트다. 신규 픽셀 표현에 대한 사용자 미술 승인, 이동/공격 모션·Unity import/피벗 연결·실제 전투 확인은 후속 범위다.
