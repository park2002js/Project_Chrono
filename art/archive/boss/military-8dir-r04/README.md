사용자가 R03 몸체의 명암이 너무3D 같다고 피드백하여, 기존 Aseprite의 색을 다시 칠했다. 사용자가 원하는 방향은2D 느낌이며, 아래의 구체적인2톤 처리는 AI의 시험 해석이다. 새 표현의 사용자 미술 승인은 아직 받지 않았다.

## 이번 표현과 재사용할 지시문

> 형태·크기·8방향 구도는 유지하고, 몸통과 머리의 명암을2D 도트처럼 다시 칠해줘. 윗면·옆면마다 밝기를 다르게 나누지 말고 넓은 기본색과 그림자 한 단계로 정리해줘. 큰 윗면 하이라이트와 모서리의 여러 명암 띠는 없애고, 아래쪽과 부품이 겹치는 곳에만 짧은 그림자를 남겨줘. 국방색·모래색·청회색의 재질 구분은 유지해줘.

몸통·머리·어깨·발등의 넓은 면을 기본 국방색 `#74834E`로 합치고, 하단 약2px와 머리 아래 접촉부에 `#50613D` 그림자를 배치했다. 등 박스의 밝은 모서리색도 짙은 기본색으로 통합했다. 깊은 틈·윤곽선과 모래색 판·금속·양손 발사기·붉은 슬릿·손등 수정은 유지했다. 단순히 전체 색 수를 줄이는 대신 큰 면을 나누던 광원 명암을 없애는 변경이다.

## 보존한 규격

- 각 PNG/프레임144×144px, 투명 배경, 알파0/255
- 순서 `S, SE, E, NE, N, NW, W, SW`,8개 정지 방향 프레임·8개 태그·7개 부위/윤곽 레이어
- R03의 정사영 고도30°·모델 단위당27px·지면 피벗(72,120)에서 만든 모든 픽셀 위치와 외곽 보존
- 다시 투영하거나 방향별 크기를 조정하지 않고 기존 native 셀의 색만 변경
- 실제23색, 안티앨리어싱·디더링 없음
- 가로 시트1152×144px. native 프레임100ms는 이동 모션 시간이 아니며 GIF500ms는 방향 검토용

PNG는 [정면 S](png/S.png), [SE](png/SE.png), [E](png/E.png), [NE](png/NE.png), [후면 N](png/N.png), [NW](png/NW.png), [W](png/W.png), [SW](png/SW.png)를 제공한다.

## 확인 결과와 남은 범위

[독립 native 검사](validation-independent.json)에서8프레임 재개봉·재출력 PNG의 RGBA 차이0, R03 대비 모든 알파 차이0, 반투명 픽셀0을 확인했다. [보존 검사](source-preservation-validation.json)에서 기존3D R05와 픽셀 R03의38개 파일 해시가 그대로임을 확인했다. [구성 정보](manifest.json)에 변경 출처·카메라·팔레트·색 변경 수를 기록했다.

전후 비교와8방향 검토에서 넓은 상면광 감소, 대각 구도와 부품·재질 구분 유지를 확인했다. 이번 결과는 명암 시험을 적용한 정지 방향 자산이며, 이동/공격 모션과 Unity 연결·실제 전투 확인은 수행하지 않았다.
