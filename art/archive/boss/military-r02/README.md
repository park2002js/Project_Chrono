# 군용 로봇 정면 R02

**이전 시안:** 현재는 좌우 대칭·여러 재질색을 적용한 [R03](../military-r03/README.md)을 사용한다.

2026-11-16 사용자 수정 요청을 반영한 Aseprite 정면 시안이다.

- [검사 결과](validation.json)

노란 장갑을 올리브 국방색과 검회색 관절로 바꾸고, 머리를 밝은 윗면·정면·어두운 우측면의 직육면체로 다시 그렸다. 원래의 붉은3슬릿·큰 양팔·두 다리는 유지했다.

실제 불투명 경계는69×82px에서104×123px로 커졌다. 가로는 픽셀 반올림으로1.507배, 세로는1.5배다. 캔버스112×136px,10레이어·18색·정면1프레임이다.

등 수정은 몸체에 비해 작게 조정했다. 좌우 꼭짓점의 설계 간격을 기존28px의1.5배인42px 대신32px로 잡아 비례 확대보다 약24% 작게 했다. 이 간격은 양끝 픽셀을 모두 포함한 경계 폭과1px 차이가 있으며, 기존 이미지보다 절대 픽셀 수가 줄었다는 뜻은 아니다.

원본을 재열어 PNG 전픽셀 일치·이진 알파·잘림 없음을 확인했고 이전 R01 native/PNG 해시를 보존했다. 다른7방향·애니메이션·Unity 연결은 별도다. 현재 기준은 [GAME_SPEC3.3.12](../../../../docs/GAME_SPEC.md#3312-보스-6종-탑다운-정면-시안--front-r01)을 따른다.
