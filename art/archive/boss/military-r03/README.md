# 군용 로봇 정면 R03

**이전 정면 보관본:** 현행은 정면까지 포함해 몸통을 두껍게 다시 그리고 등 수정·고정 장치를 제거한 [8방향 R02](../military-8dir-r02/README.md)다. R03 원본 파일은 이력으로 보존했다.

2026-11-16 사용자 요청에 따라 R02를 좌우 대칭으로 맞추고 재질별 색상을 섞었다.

- [투명 PNG](png/02-military-robot-front.png)
- [6배 확대](preview-6x.png)

국방색 장갑을 중심으로 모래색 어깨·복부 삽입판과 발끝 띠, 청회색 장갑·관절, 좌우 한 쌍의 어두운 적색 정비 표시를 배치했다. 큰 색 덩어리를 재질과 부위별로 나누었으며 무작위 점무늬는 넣지 않았다. 등 수정과 붉은3슬릿은 유지했다.

머리는 밝은 윗면·직사각 정면·같은 폭의 양측 경사면으로 구성했다. 전체 RGBA 픽셀과 개별 레이어 모두 캔버스 중앙 x=55.5 기준으로 정확히 좌우 대칭이다.

캔버스112×136px, 실제 불투명 경계102×122px,10레이어·31색·정면1프레임이다. 대칭에 맞춰 경계를 정리하면서 이전 실체104×123px보다 각각2px/1px 작아졌고 큰 확대 크기는 유지했다.

Aseprite 원본 재열기/PNG 차이0, 전체/레이어 대칭 차이0, 중간 알파0, 가장자리 접촉0을 확인했다. 이전 R02 native·PNG SHA256은 보존했다. 최종 미술 선택·다른 방향·애니메이션·Unity 연결은 별도다.
