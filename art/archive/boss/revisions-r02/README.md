# 보스 디자인 피드백 R02

**후속 수정:** 경비·군용·뱀은 [R03](../revisions-r03/README.md)이 현행이다. 아래 비교는 R02 이력이며 연구자 기본형/흩날림은 계속 사용한다.

[이번4종을 Player와 동일3배로 비교](comparison.png)

| 대상 | 현재 원본·출력 | 변경 |
| --- | --- | --- |
| 경비 로봇 | [편집·PNG 안내](../guard-r02/README.md) | 흑백 경찰색·빨간 사이렌·매립 수정·5총구·평평한 밑면, 몸통1.5배·주먹 높이40px |
| 군용 로봇 | [편집·PNG 안내](../military-r02/README.md) | 국방색·약1.5배·등 수정 비율 축소·직육면체 머리 |
| 뱀 | [편집·PNG 안내](../worm-r02/README.md) | 검보라 수정 마디/밝은 일반 마디 구분, 두꺼워진 마디·가는 마력선·가지 전류 제거 |
| 연구자 | [기본형·모션 안내](../researcher-r02/README.md) | 30×30 일반 남성·연구 가운·사각 손, 기본형과 머리/가운 흩날림6장 |

꽃은 사용자 의도에 맞춰 **2D 제작 대상에서 제외**했다.3D 모델 import는 아직 수행하지 않았다. 슈트 맨은 기존 R01을 유지한다. 이전 시안은 이력으로 보존했으며 현재 제작 결과는 위 링크를 사용한다.

모든 출력은 Aseprite 원본을 다시 열어 검사했다. 상세 근거는 각 폴더의 검사 기록과 [로봇 공동 검사](../robots-r02/validation.json)에 있다. 비교판은 입력4원본의 픽셀을 바꾸지 않았으며 [배치 기록](manifest.json)에 크기와3배 표시를 남겼다. 이번 작업에서 Unity 연결은 수행하지 않았다.
