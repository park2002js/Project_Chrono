# 보스 수정 R04

**후속 수정:** 경비 주먹은 윗면·측면 입체감을 보강한 [R05](../guard-r05/README.md)로 갱신했다. 뱀은 R04를 유지하며 [현재 전체 비교](../lineup-r05/README.md)를 따른다.

[경비·뱀 크기 비교 및 손·마디 상세](comparison.png)

보스와 Player는 동일 3배, 손 상세는 4배, 마디 상세는 8배다. 확대는 최근접 방식이며 [배치 기록](manifest.json)에 원본 경로와 배율을 남겼다.

| 대상 | 편집 원본 | 변경 |
| --- | --- | --- |
| 경비 로봇 | [Aseprite](../guard-r04/aseprite/01-guard-robot-front.aseprite) · [안내](../guard-r04/README.md) | 각 손은 손가락 3개와 엄지 1개. 기존 34×40px 크기·외곽 유지 |
| 뱀 | [Aseprite](../worm-r04/aseprite/03-electric-worm-front.aseprite) · [안내](../worm-r04/README.md) | 첨부는 27×27px 크기만 참고. 등판과 장갑선을 새로 제작 |

뱀 R03에서 첨부의 윤곽·면 분할까지 복제한 것은 AI의 잘못된 해석으로 사용자가 거절했다. R04는 크기만 참고해 새로 그린 수정본이며 최종 미술 확정 여부와 구분한다.

군용 로봇은 R03, 연구자 기본형/흩날림은 R02, 슈트는 R01을 유지한다. 꽃은 2D 제작 대상에서 제외한 상태다. 이번 수정은 정면 원본·PNG에 반영했고 Unity 연결은 수행하지 않았다.
