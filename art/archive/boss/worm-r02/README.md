# 전기 뱀 정면 R02

**이전 시안:** 현재는 사용자 첨부27×27px 윤곽으로 다시 구성한 [R03](../worm-r03/README.md)을 사용한다.

2026-11-16 사용자 피드백으로 수정 마디와 일반 마디의 외형을 구분하고 부피·윤곽을 수정했다.

수정이 있는 꼬리·중간·머리3마디는 검보라색으로 잠식된 장갑이며, 나머지5마디는 밝은 아이보리 장갑이다. 일반 마디의 마력선은1px 두께의 실처럼 줄였다. 몸 밖으로 뻗던 가지형 전기 장식은 전부 제거했다.

8마디 모두 같은31×34px의 둥근 껍질을 사용한다. 이전31×24px보다 세로 부피를 늘리고 윗면·옆면·하단 명암으로 구분했다. 전체 캔버스112×176px, 실제 불투명 경계93×167px,9레이어·22색·정면1프레임이다.

Aseprite 재열기/PNG 전픽셀 일치, 중간 알파0, 외곽 잘림 없음과 확대 모습을 확인했다. 이전 R01 native·PNG는 보존했다. 최종 미술 선택·나머지 방향·움직임·Unity 연결은 별도이며 [GAME_SPEC3.3.12](../../../../docs/GAME_SPEC.md#3312-보스-6종-탑다운-정면-시안--front-r01)을 따른다.
