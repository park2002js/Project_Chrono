# 뱀 정면 R03 — 첨부27×27px 마디

**사용자가 거절한 이전 시안:** 첨부는 크기 기준이었으나 AI가 윤곽·면 분할까지 복제한 것은 잘못된 해석이다. 현행은 크기만 참고해 새로 그린 [R04](../worm-r04/README.md)다. 아래는 당시 제작 사실을 남긴 이력이며 승인된 디자인 지시가 아니다.

사용자가 제공한 [27×27px 마디 원본](segment-reference-27x27.png)의 윤곽·면 분할과 크기를 기준으로 다시 구성했다. 원본의5색을 기존 밝은 회백색/검보라색으로 치환한 뒤, 가는 마력선·수정·머리 안쪽 입을 표현했다.

- [Aseprite 원본](aseprite/03-electric-worm-front.aseprite)
- [투명 PNG](png/03-electric-worm-front.png) · [6배 확대](preview-6x.png)
- 27×27px 단위 출력: [일반](png/modules/normal-27x27.png) · [수정](png/modules/crystal-27x27.png) · [머리](png/modules/head-27x27.png)
- [검증 결과](validation.json)

마디는8개이며 밝은 일반 마디5개, 검보라 수정 마디3개(머리 포함)다. 각 마디의 native 셀과 개별 PNG는27×27px이고, 세 종류 모두 원본과 불투명577px·알파 윤곽이 완전히 같다. 이전31×34px 껍질을 확대/축소한 이미지가 아니다. 몸 밖의 가지 전기는 넣지 않았다.

전체 캔버스104×152px, 실제 불투명 경계89×144px,9레이어·19색·정면1프레임이다. Aseprite 재열기와 PNG 전픽셀 일치, 중간 알파0, 잘림 없음 및 각 마디의 원본 알파 차이0을 확인했다.

이전 R02는 보존했다. 다른 방향·애니메이션·Unity 연결은 아직 수행하지 않았으며 현재 기준은 [GAME_SPEC3.3.12](../../../../docs/GAME_SPEC.md#3312-보스-6종-탑다운-정면-시안--front-r01)을 따른다.
