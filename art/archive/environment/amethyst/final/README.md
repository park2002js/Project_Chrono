# 자수정 최종 원본·출력

사용자 수정 형태와 승인된 어두운 보라색 비활성·선명한 보라색 활성 상태를 사용한다. 활성은 몸체만2px 범위에서1.6초 주기로 부유하고 그림자는 고정한다.

| 위치 | 내용 |
| --- | --- |
| [aseprite](aseprite/) | 비활성1프레임·활성8프레임과 배치 편집본 |
| [사용자 수정 원본](source/amethyst-user-edited.aseprite) | 원본 바이트를 보존한 편집 입력 |
| [unity](unity/) | 비활성 PNG·활성 가로 시트·animation.json |
| [preview](preview/) | 현재 모양·부유 결과 |

개별 프레임16×40·활성 시트128×40,16PPU·Point·무압축·Mipmap 없음, Sprite pivot(0.5,0.1)이다. 실제 몸체16×32 외의 공간은 부유·그림자 여백이다. 원본 전체 맵의 바닥 앵커는(200,464)px이며 크롭 배치와 전체 맵 배치를 혼동하지 않는다.

편집 후 같은 프레임 크기·바닥 앵커로 PNG를 출력하고 기존 meta를 보존한다. 실제 수정 F 상호작용·회복·저장·문 개방과 Active 전환은 게임에 연결했으며 현재 규칙은 [GAME_SPEC](../../../../../docs/GAME_SPEC.md)의 F-P10을 따른다.
