# 화면 아래에서 들어오는 최초 입장 R02

Player 전체가 화면 아래에 숨은 상태로 시작하고, 고정된 화면의 정중앙에 도착하면 조작을 인계하는 후속 수정입니다. [R01 기록](../entrance-corridor-r01/README.md)은 그대로 보존합니다.

| 항목 | R02 적용값 |
| --- | --- |
| 출발점 | `(14.5, -5.6)` |
| 정지점·입장 중 카메라 목표 | 기존 start `(14.5, 1.4)` |
| 자동 보행 거리 | 위쪽 `7world` |
| 기본 카메라 세로 반크기 | `5.625` 유지 |
| 고정 화면 아래·위 | `-4.225` · `7.025` |
| 출발 시 몸체 전체 Rect의 위쪽 | `-4.35`, 화면 아래로 `0.125world`(2px) 여유 |
| 맵 남쪽 바닥·차단선 위쪽 | `-6` 유지 |
| 출발점의 바닥 차단선 위 여유 | `0.4world` |
| 기존 확장 타일·경계 | 6행·216셀·Collider 5개 유지 |

[편집 원본](authoring/MapEntranceSetup.cs)은 출발점 계산만 `SouthExtensionRows + 1`, 즉 정지점에서 7world 아래로 바꿉니다. 이 아트 담당은 Map 원본 프리팹을 직접 쓰거나 Unity를 실행하지 않았으며, WorldCamera 프리팹·기본 줌·일반 추적 오프셋·맵 크기·타일과 팔레트를 추가 변경하지 않습니다. 수치와 사전 해시는 [manifest.json](manifest.json)에 보관합니다.

몸체는 20×20px·16PPU·발 밑 중앙 pivot이므로 Player 상대 전체 Rect가 `y0~1.25`입니다. 위쪽 조준의 Idle 검 위쪽은 상대 약 `0.929`로 몸체보다 낮습니다. 화면 아래 `-4.225`보다 전체가 낮으려면 출발 Y가 `-5.475` 미만이어야 합니다. 몸체 Collider는 `0.5×0.35`, offsetY `0.175`라 아래 끝이 Player 원점이며, 남쪽 차단선 `-6`과 skin `0.01`을 고려한 범위 안에서 `-5.6`을 사용합니다. 이 기하 계산 뒤 실제 첫 렌더에서 몸체 viewport 위쪽 `-0.01111108`, 검 위쪽 `-0.03982651`로 모두 화면 밖임을 확인했습니다.

입장 준비는 Player 생성·Bind 뒤에 진행합니다. 로딩 아래에서 몸체와 검의 위쪽 조준을 즉시 맞추고 이동 명령을 비운 뒤, 기존 정지점 Transform으로 카메라를 고정합니다. 첫 빈 화면 1프레임 뒤 실제 보행을 시작하고 도착하면 정상 Player 추적을 복구합니다. 정중앙은 일반 카메라가 추적하는 Player root의 viewport `(0.5,0.5)`를 기준으로 하며 발 pivot 위에 놓인 Sprite bounds 중심과 구분합니다. 기존 최초 완료 저장·취소·계속/부활 체크포인트 규칙은 유지합니다.

최종 격리 Unity6000.3.21f1 Play의 7개 검사가 모두 통과했습니다. 고정 카메라 `(14.5,1.4)`·줌 `5.625`, 첫 빈 화면과 몸체/검의 완전 비가시 상태, 실제 7world 보행·root viewport `(0.5,0.5)` 도착·도착 오차 0을 확인했습니다. 별도의 `0.0002world` 잔여 이동도 오차 0으로 적용됐습니다. 입력 차단/정지·완료 저장과 구저장·중단/재시도·카메라의 정상/취소 복구, 인계 뒤 S/A/D 보행과 Space 대시가 남쪽·양옆 경계를 넘지 않는 것도 검사했습니다.

컴파일 3.363830초·C#/Shader 오류 0·배치 종료 0이며 기존 Editor Search 예외 1회는 별도로 남습니다. 검증 시 C# 102개·런타임 56개·관련 C# 12개와 meta를 합친 24파일이 원본과 일치했습니다. Map만 기존 GUID를 유지해 출판됐고, 출판 후 Map과 meta 양쪽이 검증본과 일치했습니다. GameSystems/WorldCamera/Player 프리팹은 바꾸거나 다시 복사하지 않았습니다. 관련 로그는 `project/Logs/TutorialEntryR02-{result,metrics,verification,outputs,publication,gif-verification}.json`과 `TutorialEntryR02Final.log`입니다.

[실제 R02 입장 GIF·시작/인계 화면](../../map/player-entrance-r02/README.md)을 보관합니다. 원본 PNG 39장 중 연속으로 동일한 빈 프레임 하나를 시간을 유지해 병합한 GIF 38프레임·총 2.42초이며 마지막 800ms는 관찰용 hold입니다. GIF 양자화 왕복 검증도 통과했습니다.

R01 기록과 R02의 첫 허용오차 검사 성공 이력은 보존합니다. 첫 R02 실행은 기존 허용오차로 통과했으나 실제로 `0.0097523world` 먼저 인계되어, 이후 정밀도 기준과 작은 잔여 이동 검사를 강화한 최종 결과를 위에 기록했습니다. 이전 오라 검증 Guard/Map fixture는 원본으로 재동기화했으며 재생성하지 않았습니다. Temp 세이브만 사용했고 원본 프로젝트 직접 Play와 빌드는 미실행입니다.
