# 최초 입장 복도 최종 배치

첫 입구문이 보이지 않는 고정 화면에서 실제 Player가 걸어와 중앙에서 조작을 인계한다.

| 항목 | 현재 값 |
| --- | --- |
| 저장 체크포인트 | (14.5,1.4) |
| 최초 입장 출발점 | (14.5,-11.6) |
| 입장 종료점·고정 카메라 중심 | (14.5,-4.6) |
| 자동 보행 | 위로7world |
| 남쪽 추가 타일 | 12행/432셀 |
| 카메라 세로 제한 | [-12,77] |
| 기본 줌 | 5.625 |

기존 저장 체크포인트와 별도 입장 종료점을 구분한다. 첫 입구문의 최하단y3은 고정 화면 위쪽y1.025보다 높아 문 전체가 화면 밖에 머문다. 중앙 기준은 Sprite bounds가 아닌 Player root의 viewport(0.5,0.5)다.

배치·치수는 [manifest.json](manifest.json), 실제 결과는 [최종 입장 영상](../../map/player-entrance-r03/README.md)에 있다. 입장·완료 저장·중단 복구·걷기/대시 경계의7검사를 확인했다. 안내·대사 전체 튜토리얼 구현을 뜻하지 않는다.
