# 문이 보이지 않는 복도에서 입장 종료 R03

첫 입구문이 보이지 않는 위치를 카메라 중심과 입장 종료점으로 사용합니다. 남쪽 복도 확장을 기존 6행에서 12행으로 늘리되 실제 자동 보행은 7world를 유지합니다. [R01](../entrance-corridor-r01/README.md)·[R02](../entrance-corridor-r02/README.md) 기록은 보존합니다.

| 항목 | R03 적용값 |
| --- | --- |
| 기존 저장 체크포인트 start | `(14.5, 1.4)` 유지 |
| 최초 입장 출발점 | `(14.5, -11.6)` |
| 별도 입장 종료점·고정 카메라 중심 | `(14.5, -4.6)` |
| 자동 보행 거리 | 위로 `7world` 유지 |
| 기본 줌·고정 화면 아래/위 | `5.625` · `-10.225 / 1.025` |
| 첫 입구문 Sprite의 아래 끝 | `y3`, 화면 위쪽보다 `1.975world` 높음 |
| 출발 시 몸체 Rect 위쪽 | `-10.35`, 화면 아래로 `0.125world`(2px) 여유 |
| 남쪽 바닥/경계 위쪽·출발 여유 | `-12` · `0.4world` |
| 남쪽 추가 타일 | 총 `12행 / 432셀`, R02보다 `6행 / 216셀` 추가 |
| 카메라 세로 제한 | `[-12, 77]` |

[편집 원본](authoring/MapEntranceSetup.cs)은 기존 타일의 0~3행 참조를 반복해 전용 확장 레이어를 채웁니다. 행마다 바깥 29개·바닥 5개·벽 2개입니다. 하단·입구 양옆·외곽 양옆의 기존 Collider 5개만 남쪽으로 늘리며, 다른 방·문·수정·Boss·팔레트와 GUID를 보존합니다. 기존 Map/Camera API와 전체 아트 생성기 연결을 그대로 재사용하고 재적용 시 중복 레이어/마커를 만들지 않습니다.

출발점은 기존 체크포인트에서 `rows + 1 = 13world` 아래로 배치합니다. 새 독립 `EntranceStopPoint` 마커는 출발점의 7world 위에 생성합니다. 저장 체크포인트 Transform을 이동하거나 종료점으로 재사용하지 않습니다. 기존 TutorialController가 Map의 이 마커 참조를 읽으므로 런타임 코드 수정 없이 고정 화면·빈 첫 화면·위쪽 조준·중앙 도착과 카메라 복구를 이어갑니다. 정중앙 기준은 정상 카메라가 추적하는 Player root의 viewport `(0.5,0.5)`입니다.

카메라 하단 제한 `-12`와 기본 줌을 적용하면 중심 하한은 `-6.375`여서 목표 `-4.6`이 경계에 밀리지 않습니다. 화면 위쪽 `1.025`는 첫 문 Sprite 전체의 최하단 `3`보다 낮아 문이 보이지 않는 기하입니다. 문 Sprite 중심 `5`, 루트 원점 `3`, 통과 차단선 물리 중심 `4.5`는 서로 구분합니다. 첫 화면의 Player 몸체/검 숨김도 R02와 같은 2px 여유를 유지합니다.

격리 Unity6000.3.21f1 Play의 실제 7개 검사가 모두 통과했습니다. 기존 체크포인트 `y1.4` 유지·독립 종료점 `y-4.6`·12행/432셀·고정 카메라/줌을 확인했습니다. 첫 화면 몸체 viewport 최대Y `-0.01111114`·검 `-0.03982657`로 완전히 화면 밖이고, 촬영 전체에서 첫 문 Sprite의 최소 viewport Y가 `1.17555559`로 화면 위쪽에 머물렀습니다. 실제 7world 보행·root viewport `(0.5,0.5)` 도착 오차 0·`0.0002world` 잔여 이동 오차 0, 걷기 Sprite 6종·발소리 5회도 확인했습니다.

검사에는 입력 차단/정지·카메라 정상/취소 복구·인계 뒤 S/A/D 보행과 Space 대시의 남쪽/양옆 경계 제한·완료 표식 디스크 재로드와 구저장 건너뛰기·실제 벽 충돌과 제거 후 재개·Title 중단/재시도·이전 코루틴의 뒤늦은 입력 해제 방지가 포함됩니다. 컴파일 2.971914초·C#/Shader 오류 0·배치 종료 0이며 기존 Editor Search 예외 1회는 별도로 남습니다. 검증 시 C# 102개·런타임 56개·관련 C# 12개와 meta를 합친 24파일이 원본과 일치했습니다.

기준 해시 확인 뒤 Map과 WorldCamera 두 프리팹만 GUID를 유지해 출판했습니다. 출판 후 두 프리팹과 meta 총 4파일이 검증본과 일치하며, Player와 GameSystems는 동일하여 다시 복사하지 않았습니다. 수치·기준/출판 해시는 [manifest.json](manifest.json), 실제 근거는 `project/Logs/TutorialEntryR03-{result,metrics,verification,outputs,publication,gif-verification}.json`과 `TutorialEntryR03Final.log`입니다.

[실제 R03 입장 GIF·시작/인계 화면](../../map/player-entrance-r03/README.md)을 보관합니다. 원본 PNG 36장에서 동일한 연속 빈 프레임 하나를 시간을 유지해 병합한 GIF 35프레임·2.46초이며 마지막 800ms는 관찰용 hold입니다. 촬영 전 구간의 문 비가시 상태와 GIF 양자화 왕복 일치를 확인했습니다.

R01/R02 기록과 미디어는 보존합니다. R03은 맵 기하만 변경했고 R02에서 정밀도를 보강한 실제 이동/도착 런타임은 유지했습니다. 이전 오라 검증 Guard/Map fixture는 원본으로 재동기화했으며 재생성하지 않았고, Temp 세이브만 사용했습니다. 이 아트 담당은 마감 중 이미지/GIF·코드·프리팹을 변경하거나 Unity를 실행하지 않았습니다. 원본 프로젝트 직접 Editor Play와 빌드는 미실행입니다.
