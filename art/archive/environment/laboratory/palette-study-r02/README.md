# 밝은 연구시설·검흔 보존 배경 검토 R02

2026-11-16 사용자 요청: 조명 없이 연구시설 내부를 밝게 유지하면서 기존 검흔이 잘 구분되는 방법을 먼저 검토한다. 후속 답변에 따라 **검흔은 최대한 수정하지 않는 방향**으로 범위를 확정했다. 이 비교에서는 색·모양·알파·외곽선을 모두 원본 그대로 두었다. 앞서 검토한 외곽선안은 제외했다.

**후속 사용자 선택으로 C 절충안을 확정했고 현재 `../final/`과 Unity PNG에 반영했다.** 이 폴더는 선택 당시의 비교 기록이다. [네 가지 비교](preview/comparison.png)는 같은320×180 원본 시야를 패널당3배로 보여준다. 개별1920×1080 그림은 원본1px=화면6px다. 실제 맵과 당시 Attack1_01/Attack2_01을 사용하며2타만 실제 표현 방향대로 좌우 반전했다. 실게임 캡처·애니메이션 검증은 아니다.

| 안 | 기본 바닥 | 밝기·대비의 차이 |
| --- | --- | --- |
| A 현재 | `#626668` | 검흔은 선명하지만 밝은 시설감이 부족했던 적용 이력 |
| B 밝기 우선 | `#C2C0B6` | 시설은 밝지만 두 검흔과 바닥의 명도 차이가 작음 |
| C 밝기·대비 절충 | `#B0ADA1` | 밝은 벽과 중간 밝기 웜그레이 바닥으로 분리 |
| D 바닥 대비 보강 | `#A3A596` | C보다 바닥만 한 단계 낮춰 검흔 대비를 높인 안 |

**사용자 확정은 C**다. 밝은 시설감과 검흔 대비의 절충안을 선택했으며 실제 게임의 움직임·작은 잔상 검증과는 구분한다.

B~D는 공통으로 밝은 벽 윗면·회청색 측면을 복원하고 문을 밝은 회색으로 조정했다. 바닥 격자·크랙·무늬 위치를 유지하면서 최초 밝은 바닥의 명도 편차를0.25배로 줄였다. 공간의 밝은 인상은 벽에서, 전투 가독성은 비교적 균일한 중간 밝기 바닥에서 확보한다. 구체 RGB와 레이어별 치환은 [palette-study.json](palette-study.json)의 시험값이다.

검흔의 원래 연보라`#E5D2FF`·연하늘`#C3EAFF`와 모든 불투명 픽셀을 보존했다. 원본 기본색의 상대휘도 대비는 보라/하늘 순서로 A4.142/4.568, B1.303/1.437, C1.606/1.771, D1.789/1.973이다. 색상 계산이므로 실제 이동·잔상·피격 상황의 가독성 측정이나 접근성 기준 통과로 보지 않는다. 작은 잔상까지 포함한 실게임 확인은 적용 후 범위다.
