# Draw 선 30도 비교 시안

2026-11-16 사용자 요청: Draw에서 쓸 pixel 선과 image 기반 FX 선을 대각 30도로 각각 비교한다.

- [최종 비교판](draw-line-30deg-comparison.png): 1920×1080 PNG
- [편집·재출력 원본](Render-Comparison.ps1): 외부 의존성 설치 없이 System.Drawing으로 새 비교 도형을 렌더링
- 수평 기준 우상향 30도, 중심선 길이800px, 흰 중심 폭6px·청록 가장자리 포함10px의 같은 연속 거리 조건. A는4px 격자 표본화로 생기는 계단, B는연속 거리 기반 부드러운 알파/약한 잔광을 표현한다. A의 실제 픽셀 윤곽/끝점에는 격자 양자화가 적용된다.
- 두 개의 아래 창은 같은 조건을4배 확대한 경계 표현이다. 실제 Unity 캡처나 게임 카메라 배율이 아니다.
- 후속 선택(2026-11-16): 사용자가 image FX 방식을 선택해 현재 Draw에 적용하고 점은 표시하지 않도록 요청했다. 비교판 수치는 당시 제작 제안이며 게임의 색상·두께·잔광은 선택 스타일에 맞춘 현행 적용값이다. 적용/확인 상태는 [GAME_SPEC3.3.13](../../../../docs/GAME_SPEC.md#3313-draw-이미지-fx-적용--draw-line-image-r01)을 따른다.
- 도구: 내장 image_gen으로 초기 스타일 시안을 생성하고 보정했으나 각도 고정이 충족되지 않아, 최종판은 생성 이미지를 변형하지 않고 정확한30도 도형을 새로 직접 렌더링했다.
- 최종 렌더 조건: “동일30도·길이·중심 굵기·청백색의 선. 왼쪽은단단한 도트 계단형, 오른쪽은매끈한 알파 텍스처와 약한 잔광. 각 경계를4배로 비교. 캐릭터·배경 장식·파티클 제외.”
- 확인: 삼각함수 좌표의30도 자체검사, PNG 재열기1920×1080, 최종 시각검토. 초기 생성판은정확한30도 비교 결과로 사용하지 않는다.

image FX도 픽셀 아트 텍스처로 만들 수 있으므로 이 판은 매체의 배타적 분류가 아닌 시각 스타일 두 가지를 비교한다.
