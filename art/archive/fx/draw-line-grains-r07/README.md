# Draw 원형 알갱이 R07

사용자는 R06의 빛 조각 모양을 정정하고 더 작은 원형 알갱이가 날아가는 연출을 요청했다. 실제 확산·상승·알파 소멸·정지/정리 구조는 유지하고 입자의 모양과 크기만 바꿨다. 이 결과의 사용자 미술 승인은 아직 받지 않았다.

- 입자는 가로·세로가 같은 직경0.045~0.085월드 단위의 작은 원이다. 전용 셰이더가 밝은 중심·청록색·부드러운 알파 경계를 표시하며 선 텍스처를 축소해서 사용하지 않는다. 입자 회전은0이다.
- 원래 R04 선 이미지·두께·양끝 오라·길이 연동은 유지한다. 알파 왕복 뒤 총1.3초 동안 기존처럼 양옆·위로 실제 이동하고, 크기 변화 없이 알파로 사라진다. 6길이72개·12길이144개와 재사용 수명도 유지한다.
- 기존 컴포넌트·셰이더·재질의 GUID를 보존했다. `PlayerDrawSetup.PrepareEvaporationMaterial()`은 원형 셰이더만 연결하고 입자 텍스처를 설정하지 않는다.

## 실제 녹화와 검사

`draw-grains-preview.gif`는 Unity Game View1093×515의 실제30° 선 녹화다. 원본48캡처가 동일 화면 병합 후46 GIF프레임·4초로 저장됐다. 관찰 게임 시간은3.526698초이며 마지막0.5초는 반복 전 빈 화면 여백이다. 검사 튜닝은 Line 수명2.4초·경고 비율0.9·왕복 주기0.4→0.08초·증발1.3초이며, 게임 기본 경고 비율0.35/주기0.5→0.08초와 구분한다. `Encode-Preview.py`·시간 CSV·입자 CSV·검사JSON·실제 PNG4장·셰이더를 함께 보관했다.

실제72입자의 직경은0.046440~0.084193, 가로/세로 차이0·수명 중 크기 변화0이었다. 같은 식별자로 추적한 X변위는 약−1.345~+1.419·최대 상승2.179월드 단위,72개 모두 알파 감소·마지막 입자0개를 확인했다. GIF 표본 평균 RGB 오차는0~255기준 약0.007~0.058이다.

Unity6000.3.21f1 격리 컴파일·Draw/편집/수명/Slash/Title23묶음 성공·프로세스 종료0을 확인했다. 원형 크기·실제 이동·고정 크기·알파·정지·표시 복구·재사용·교체·사망·Title 정리를 포함한다. C#81개 검증 사본을 기록했고 현재 런타임48개·Draw소유11파일은 사본과 일치한다. 이후 병행 작업의 Editor3개(BossHazardArtChecks·BossHazardArtSetup·PlayerAttackIntegrationChecks)는 달라 전체 최신 Editor 일치로 주장하지 않는다.

실행은 검증 사본에서 기존 Player/Slash 준비 도구를 호출한 뒤 Draw 검사를 실행했다. 확인된 `DrawEvaporation.mat`만 원본으로 복사했으며 사본의 Player 전체·공격/보스/Slash 자산은 복사하지 않았다. 원본 R04 PNG 해시 `798FC9A404D216339A0F4C80439E17A0C5A2E8DDCD2E44AC25A3913CB98373D8`를 보존했다. 로그·source/scope/result는 `project/Logs/DrawGrainsVerification` 이름으로 보관한다. 원본 Editor 직접 Play/최종 import·제출 빌드는 미확인이다.
