# Draw 원형 알갱이 테두리 R08

사용자는 R07 원형을 유지하면서 바닥에서 흐릿한 알갱이 주변에1px를 더 둘러 달라고 요청했다. 밝은 중심·청록 원형의 바깥에 진한 청록 테두리를 추가했다. 화면 기준50% coverage 경계가 기존 반경+1px이며, 경계 안티앨리어싱에0.5px를 추가 확보한다. 렌더 외경은 총2px 커지며 ParticleSystem의 원래 월드 직경은 바꾸지 않는다.

`DrawEvaporationVfx.Prepare`에서 Position/Color/UV/UV2/Center를 한 번 연결한다. 셰이더는 입자 월드 중심과 화면 정점의 차이로 외측 방향을 결정해 쿼드를1.5px 확장하고, fragment에서 원래 반경을 복원한다. 원래 중심/soft alpha를 진한 청록 위에 합성하고 전체 테두리에 같은 수명 알파를 곱한다. 작은 원형·실제 확산/상승·알파 왕복/소멸·정지/정리 흐름과 R04 선은 유지한다.

## 실제 확인

같은 Unity6000.3.21f1 격리 사본에서 C#/shader 컴파일 오류0·Draw/편집/수명/Slash/Title23묶음 성공·프로세스 종료0을 확인했다. 실제 native BakeMesh의 TEXCOORD1 중심 데이터가 정점마다 존재하고 첫 쿼드의 정점 평균과 일치하는 검사도 포함했다. 초기 예약어 충돌과 UV 방향을 화면 방향으로 가정해 발생한 축소는 수정했고, 최종 GPU 화면에서 원형 외곽과 밝은 타일 위 가독성을 확인했다.

`draw-grains-preview.gif`는 실제30° 선의 Game View1093×515 녹화다. 원본66캡처가 동일 화면 병합 후64프레임·3.86초로 저장됐다. 관찰 게임 시간3.486174초, 마지막0.5초는 반복 전 빈 화면 여백이다. 검사 튜닝은 Line 수명2.4초·경고 비율0.9·왕복 주기0.4→0.08초·증발1.3초이며 게임 기본값과 구분한다. PNG4장·입자/시간CSV·검사JSON·셰이더·인코더를 보관했다.

72입자 표본의 월드 직경0.046440~0.084193·가로/세로 차이0·크기 변화0, X변위 약−1.363~+1.442·최대 상승2.118월드 단위,72개 알파 감소·마지막 입자0개를 확인했다. GIF 표본 평균 RGB 오차는0~255기준 약0.008~0.052다. 외곽1px는 셰이더의 화면 공간 계산값이며 이 월드 직경 표본과 구분한다.

## 범위

C#81개 검증 사본을 기록했고 현재 Draw소유11파일은 사본과 일치한다. 병행 작업 이후 현재 런타임45개가 일치하며 런타임3개(CircleWarningVfx·AttackController·PlayerCharacter)와 Editor5개 차이는 `project/Logs/DrawGrainOutlineVerification-scope.json`에 구분했다. 전체 최신 원본을 검증한 것으로 주장하지 않는다. 같은 이름의 `.log`·source/result JSON에 실제 결과를 보관했다.

원본에는 입자 준비 코드·셰이더·관련 검사만 수정했다. Player/재질 GUID는 보존했으며 검증 사본의 Player 전체·다른 작업 자산은 복사하지 않았다. 원본 Editor 직접 Play/최종 import·제출 빌드와 새 결과의 사용자 미술 승인은 미확인이다.
