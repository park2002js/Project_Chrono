# 최초 입장 최종 영상

[실제 입장 GIF](player-entrance.gif) · [중앙 도착·조작 인계](player-entrance-handoff.png)

Player가(14.5,-11.6)에서 독립 종료점(14.5,-4.6)까지7world 걸어온다. 고정 카메라와 줌5.625를 사용하며, 출발 시 몸체·검은 화면 아래에 있고 첫 입구문도 화면 위쪽에 숨는다. 도착하면 일반 추적·HUD·입력을 복구한다.

저장 체크포인트(14.5,1.4)는 이동하지 않는다. 완료 저장·구저장·중단/재시도·정지·벽 충돌과 조작 인계 후 경계를 포함한7검사를 확인했다. [배치 규칙](../../environment/entrance-corridor-r03/README.md)과 [manifest.json](manifest.json)을 함께 사용한다.

GIF 마지막800ms는 도착 관찰용 유지 시간이다. 전체 안내·대사 튜토리얼의 완료 자료로 해석하지 않는다.
