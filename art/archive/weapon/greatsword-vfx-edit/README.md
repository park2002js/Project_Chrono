# 대검 검기 수정 작업실

**1타는 연보라,2타는 연하늘 단색이며3타도 같은 방향에 같은 색을 사용합니다.**

- [1타 — 연보라 #E5D2FF](aseprite/greatsword-swing.aseprite)
- [2타 — 연하늘 #C3EAFF](aseprite/greatsword-swing-attack2.aseprite)
- [3타 — 아래쪽 끝을 중심으로 모은 호 교차](aseprite/greatsword-swing-attack3.aseprite)
- [1·2·3타 전체 비교](attack-combo-preview.png)·[1·2타 비교](attack2-palette-preview.png)
- [3타4장 비교](attack3-x-preview.png)·[순서 재생 GIF](attack3-x-preview.gif)

1·2타는 `VFX_EDIT`,3타는 `SLASH_A_EDIT`·`SLASH_B_EDIT` 레이어에서 수정합니다.1·2타 편집 파일/출력은 반전 전 방향이며 실제2타에서는 좌우 반전합니다. 비교판에는2타를 반전해 보여줍니다.

1. 타임라인의1~4번 프레임에서 원하는 모양·색을 수정합니다.
2. 같은 파일에 저장합니다.
3. 전용 출력 도구를 더블클릭합니다: [1타](Export-PNG.cmd)→`png/`, [2타](Export-PNG-Attack2.cmd)→`png-attack2/`, [3타](Export-PNG-Attack3.cmd)→`png-attack3/`. 개별4장과 시트가 갱신됩니다.

이후 사용할 이미지와 **나오게 할 공격 프레임 번호**를 알려주면 그 지시에 맞춰 Unity에 연결합니다. 이 파일의 미리보기 시간은 게임 재생 시점의 확정값이 아닙니다.

## 현행 색과 형태

| 대상 | 색 | 형태 |
| --- | --- | --- |
| 1타 /3타 A | 연보라 `#E5D2FF` 단색 | 원본 방향의 호 |
| 2타 /3타 B | 연하늘 `#C3EAFF` 단색 | 반전 방향의 호 |

1·2타는 전체 불투명RGB만 바꿨습니다.4장 형태·알파·셀 위치·피벗과 숨김 원본 비교/가이드는 유지합니다. 이전 흰색1타와 흰색+금빛 주황 외곽2타는 이번 사용자 지시로 대체됐습니다.

3타는 기존 호4장을 두 벌로 사용해 한 벌을 반전하고, 서로 반대 방향으로 기울이고 눌러 치우친 타원 호로 만들었습니다. 이번 수정에서는 위쪽 호와 중앙 교차를 유지하고 **아래쪽 끝을 중심으로 모았습니다.** 마지막 잔광의 좌우 간격은61px에서29px로 줄었습니다.

- 1번: 비스듬한 두 호가 중앙에서 교차
- 2번: 안으로 모인 양쪽 꼬리로 소멸
- 3번: 작은 꼬리 조각만 유지
- 4번: 각 검기의 마지막 잔광1픽셀씩 유지한 뒤 소멸

`SLASH_A_EDIT`는1타 방향의 온전한 연보라 호, `SLASH_B_EDIT`는2타 방향의 온전한 연하늘 호입니다. `CROSSOVER_A_FRONT`는 중앙 위쪽A/아래쪽B가 앞에 보이도록 하는 덮개입니다. 호의 색/모양을 바꾸면 이 덮개도 함께 맞춥니다. 두 번 휘두르는 시각 연출이며 **큰 피해1회** 방침을 유지합니다. 실제 무기 모션/피해량 수치/게임 연결은 후속입니다.

## 레이어와 유지할 기준

- `VFX_EDIT`:1·2타에서 실제 수정할 이미지
- `REFERENCE_ORIGINAL`: 숨김/잠금 상태의 원본 비교용. 비교 후 다시 숨김
- `GUIDE_PIVOT`: 숨김/잠금 상태의 중심 십자
- 공통 캔버스70×66px, 중심(35,33)px,16PPU. 프레임마다 캔버스나 위치를 바꾸지 않음
- `PIVOT_KEEP_35_33` Slice에 중심점 저장
- 이미지1~4는 큰 호→남은 호→작은 조각→잔광 순서

출력 도구는 원본 비교/가이드를 자동 제외하고 새 그림 레이어는 저장 당시 보이는 상태로 포함합니다. Aseprite 저장 없이 출력하면 마지막 저장본을 사용합니다.

## 출력과 검사

각 `png/`·`png-attack2/`·`png-attack3/`에70×66 개별PNG4장,280×66 가로 시트, `frames.json`을 저장합니다. JSON에는 피벗/순서/16PPU/방향별 색/2타 반전/3타 단일피해 방침을 기록하며 게임 노출 프레임은 아직 미지정입니다.

Aseprite1.3.18.6 재열기/세 전용 출력cmd 실행과PNG/시트 일치·70×66·피벗을 확인했습니다.1·2타는 알파1895→312→30→5픽셀/숨김 원본·가이드/메타데이터 보존과 단색을,3타는 변형 대응/앞뒤/1305→167→11→2픽셀/양쪽 꼬리/잘림을 검사했습니다. 각 `attack1-validation.json`·`attack2-validation.json`·`attack3-validation.json`을 따릅니다. 최초 흰색 준비 기록 `validation.json`은 제작 당시 이력입니다.

GIF는 순서 확인용이며 반복 전 빈 화면은 휴지 구간으로 VFX의 다섯 번째 그림이 아닙니다. 미리보기 시간은 Unity 최종 시간으로 사용하지 않습니다. 원작 자료와 우리 검/Player 원본은 수정하지 않았고 이번 VFX는 아직 게임에 연결하지 않았습니다.
