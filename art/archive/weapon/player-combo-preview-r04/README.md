## 온전한 두 그림을 겹쳐 그리기

보라 원본과 반전한 하늘 원본을 각각 온전히 그립니다. 두 그림이 **겹치지 않는 픽셀은 모두 보존**합니다. 겹친 픽셀만 중앙왼쪽 하늘/중앙오른쪽 보라가 앞에 놓여 뒤쪽을 가립니다. 원본을 반으로 잘라 한쪽만 표시하지 않습니다. F37·38은 사용자 지정으로 하늘 그림 전체를 숨기는 예외입니다.

## 파일과 검사

각`attack-01/`·`attack-02/`·`attack-03/`에128×128`native/`·512×512`4x/` PNG를 저장했습니다. [manifest.json](manifest.json)의`fx_purple_image`/`fx_blue_image`가 실제 색별 이미지 번호이며,`fx_image`는 수정 전 공통 단계입니다. [vfx-timing.csv](vfx-timing.csv)에도 두 색을 따로 기록했습니다. `build_frames.py`로 재생성합니다.

272PNG의 확대 일치·원본 보존·1·2타168출력 보존·3타 변경 프레임이 정확히37/38/40인지·54검포즈 보존·겹침/비겹침·PNG/GIF/CSV/잘림을 검사했습니다. 기존4장Aseprite는 온전한 원본 이미지 보관용으로 유지하고 색별 노출만 따로 기록합니다. 몸체는 기존 고정 자세이며 Unity 연결 전 검토판입니다.
