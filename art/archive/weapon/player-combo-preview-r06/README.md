# 3타 PNG 순번 대조 R06

> 이후 사용자가40~49번째 이미지를 직접 지정했다. 현행은 [R07](../player-combo-preview-r07/README.md)이며 아래40번째잔광과41이후보존은이력이다.

사용자가 번호 기준을 **첨부한 3타 표의 첫 그림을1번으로, 왼쪽에서 오른쪽으로 세는 순서**로 확인했다. 매 행은7칸이다. 37/38/40/41번째는6행의2/3/5/6열이며, 기존 F번호와 순번은 같았다.

R05의40번째 보라V2 선택은 첨부41번째를 그대로 가져온 결과가 아니었다. R06은 **첨부41번째의 실제 보라 잔광V4를 위치까지 그대로40번째에 복사**했다. 파란V1은 유지하고 다른53장은R05 그대로 보존했다.41~54번째, 특히47번째는첨부R03과 바이트 동일하다. 37/38번째는첫큰보라만,39번째는두큰검기를 유지한다.

- [37~41번째 및 첨부41번째 직접 비교](attack-03-ordinal37-41.png)
- [전체54장](attack-03-all-frames.png) · [느린 재생](attack-03-preview.gif)

첨부41번째의 보라는5px 잔광이다. 파란 첫 검기1895px와 겹침이0px이므로, 이를 그대로 옮긴 이번 결과는 큰 파랑을 보라가 가리는 모양을 만들지 않는다. **번호 기준과 문자 그대로의 복사는 확인했지만 사용자가 의도한 가림 모양의 충족은 미확인**이다. 파일 검사 통과를 사용자 시각 의도 충족으로 기록하지 않는다.

검54포즈,1·2타168출력,원본 Sprite와 native는 보존했다. 몸체는고정이며Unity에는적용하지 않았다. 실제 색별 이미지 번호는manifest.json과vfx-timing.csv를 따른다.
