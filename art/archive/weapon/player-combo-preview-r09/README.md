# 3타 VFX 8칸 이동 R09

**실제 제공된 원본의44번부터 마지막 칸까지 VFX 트랙 전체를8칸 앞당긴 수정판이다.** 추가 첨부 후 작은 꼬리·희미한 잔광·빈 노출 칸을 모두 포함해 원본 끝까지 일대일 RGBA 보존을 재검사했다. 번호·개수의 자료 차이는 GAME_SPEC3.3.8에 구분하며, 확인하지 못한 원본 칸을 임의로 추가하지 않는다. 기존 모든 원본 그림은 보존한다.

2026-11-16 사용자 요청과 후속 답변: **첨부판의44번 이후 VFX만36번부터 시작**. 플레이어와 검은 각 프레임 그대로 유지했다. 시작점은 질문에 대한 사용자 답변으로36번으로 확정했다.

VFX 원본은 첨부와 같은 R07이며, 플레이어·검 포즈는 R08과 같은54개를 사용했다. R08에서 이미 비워둔44번을 원본으로 사용해 시작 VFX가 누락되는 일을 피했다. R08 대비 변경12장, 나머지42장과 확대본은 바이트 동일하다. 검54포즈의 RGBA·위치·회전·앞뒤·시간과 몸체 원본·합성 위치를 보존했고 모든 픽셀 변화가 이전/새 VFX 영역 안에만 있음을 검사했다.1·2타와 입력 원본은 그대로다.
