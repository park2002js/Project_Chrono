# 3타 VFX 직접 분리·복사 검토판 R10

사용자 재요청(2026-11-16): 원본44번째부터 끝까지의 VFX를 하나도 빼지 않고 순서 그대로36번째부터 이어 붙이며 Player·검은 변경하지 않는다. 이유 미기록.

[전체 프레임](attack-03-all-frames.png) · [원본44 VFX와 새36 VFX 직접 대조](source44-to-destination36-vfx.png)

R07의 실제 저장 PNG에서 보라·하늘 VFX 픽셀을 분리해8칸 앞에 그대로 복사했다. 각 원본 프레임을 몸체/검과 분리한VFX로 완전히 재현하는지 먼저 확인했다. 원본44→36,45→37 순서로 마지막 원본까지 일대일 대응하며 꼬리·잔광·빈 노출 칸의 간격을 유지한다. Player·검의54포즈·위치·회전·앞뒤·시간과 픽셀을 그대로 보존한다. `attack-03/vfx-only`와 `body-sword-only`에 분리 레이어를 저장했다.

**독립 재검사에서 R09 투명 PNG의 누락이나 순서 오류는 발견되지 않았다.** 직접 분리 방식으로 출력한 R10의54개 투명 합성 역시R09와 픽셀이 동일하다. 이를 새 모션 수정이나 없던 픽셀의 복구로 기록하지 않는다. R10은 새 경로에 저장하고 검토표 배경을 밝게 바꾸며 각 칸의 VFX 원본 번호를 명시해 실제 이동 결과를 확인하기 쉽게 했다. 검토표 배경은 투명 에셋에 포함되지 않는다.

실제 사용한 구간·전체 대응·검사 결과는 [manifest.json](manifest.json), 노출 대응은 [vfx-timing.csv](vfx-timing.csv)를 따른다. 원본과1·2타는 유지했고 Unity 적용은 하지 않았다.
