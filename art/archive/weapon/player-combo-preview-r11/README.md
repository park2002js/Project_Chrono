# 3타 큰 호부터36번째 시작 R11

2026-11-16 사용자 시각 답변: **36번째는 작은 양쪽 꼬리가 아니라 큰 호부터 시작**해야 한다. 이 답변이 이전 숫자44를 작은꼬리 원본으로 해석한R09/R10의 시각 의도를 정정한다. Player·검을 변경하지 않고 VFX 순서를 누락 없이 이어야 한다. 이유 미기록.

[전체54장](attack-03-all-frames.png) · [실제 원본/결과 대응과 검사](manifest.json) · [노출표](vfx-timing.csv)

실제 R07 PNG에서 분리한 **큰 양쪽 호부터 최종 잔광까지 모든19개 표시 노출 칸(원본31~49)을36~54에 순서대로 배치**했다.36번째=큰 양쪽 호,54번째=원본의 마지막 잔광이다.1~35의 그림은 native/4x 바이트 동일하게 유지하고 각 결과 프레임의 Player·검54포즈/좌표/회전/앞뒤/시간과 픽셀을 보존했다.1·2타와 원본 그림을 수정하지 않았다.

**사용자가 확정한 것은36번째 큰 호 시작·후속 VFX 전체 순서·Player/검 보존이다.** 실제 저장 원본의 모든 표시 노출 칸을 보존하는19칸의 구체 배치는 이번 제작 적용안이며 별도의 사용자 최종 미술/타이밍 승인으로 기록하지 않는다. 이전R10의36작은꼬리는 사용자 의도와 다르다. 검토표의 밝은 배경과 원본 번호는 확인용이며 투명 에셋에는 포함되지 않는다. Unity 미적용이다.
