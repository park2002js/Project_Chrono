# 3타 VFX37~49 →30~42 이동 R12

Player·검은 각 결과 번호의 원래54포즈를 유지한다. 이동은VFX에만 적용했으며 그림/피벗/앞뒤와13칸의 순서·간격은 바꾸지 않았다.1·2타와 원래R07/R09/R11 및 검기bank를 보존했다. 개별 투명PNG는 `attack-03/native/`, 정확한4배 확대는 `attack-03/4x/`에 있다.

`manifest.json`의13칸source/destination/FX RGBA 해시와 `vfx-timing.csv`를 따른다. 원본54장 재합성·VFX13칸 완전 일치·Player/검54포즈/비VFX필드·1~29 보존·43~54 비움·변화영역·흰 배경/잘림을 검사했다. 새 배치의 최종 미술 승인은 구분하며 Unity 적용은 수행하지 않았다.

GIF는 각 그림을80ms씩 보여주는 느린 순서 검토용이며 실제 게임 타이밍과 별도다.54장을 재열어 각RGB·순서·시간과 투명PNG 보존을 검사했다(`gif-validation.json`).
