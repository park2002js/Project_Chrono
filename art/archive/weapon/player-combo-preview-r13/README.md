# 새3타 R13 — 1타1~24 + 2타16~45

2026-11-16. 사용자 번호 오독 정정과 새 주문에 따라 이전 이동안을 대체했다. **1타의1~24번째24장과2타의16~45번째30장을 보간/대기 추가 없이 연결한 총54장**이다.1·2타 자체는 수정하지 않는다.

- [흰 배경 느린 재생 GIF](attack-03-preview.gif)

## 모션 연결

| 새3타 순번 | 원본 모션 |
| --- | --- |
| 1~24 | 1타1~24 |
| 25~54 | 2타16~45 |

번호는 첫 그림부터1이며 왼쪽→오른쪽→다음 행 순서다. 검 피벗/각도/정렬과몸체는 해당 원본 포즈를 그대로 사용했다. 기존1타23번째의 검기는 가져오지 않으며 새3타의 검기는24번째부터 배치한다.

## 검기 노출

| 합친 순번 | 보라색1타 effect | 파란색2타 effect |
| --- | --- | --- |
| 1~23 | 없음 | 없음 |
| 24~25 | 1단계 큰 호 | 1단계 큰 호 |
| 26 | **2단계 남은 호로 먼저 전환** | 1단계 큰 호 유지 |
| 27~29 | 2단계 남은 호 | 2단계 남은 호 |
| 30~32 | 3단계 작은 꼬리 | 3단계 작은 꼬리 |
| 33~35 | 4단계 마지막 잔광 | 4단계 마지막 잔광 |
| 36~54 | 없음 | 없음 |

두 검기는24번째 동시에 시작하고35번째 마지막 잔광까지 함께 유지한 뒤36번째 동시에 사라진다.1단계2→3칸/2단계4→3칸으로 보라의2단계 진입만1칸 앞당겼다. 시작24·보라26 선행·동시 종료는 사용자 지시이며 구체 종료35/나머지3칸 유지 배치는 이번 제작 적용안이다.

## 앞뒤 합성

1타 보라와2타 방향으로 반전한 파란 **전체70×66 원본**을 같은 피벗에 놓는다. 중앙x35 기준 겹친 픽셀만 **왼쪽 파랑이 위,오른쪽 보라가 위**다. 겹치지 않은 부분은 두 이미지 모두 그대로 보이며 좌우 절반을 잘라 붙이지 않는다.

26번째에는 보라2단계312픽셀 중 파랑과 겹치지 않는201픽셀을 유지하고 겹친 오른쪽111픽셀에 보라가 위로 덮인다. 파랑만 있는1784픽셀도 그대로 유지한다. 전체 알파는 두 원본 알파의 합집합이다.
