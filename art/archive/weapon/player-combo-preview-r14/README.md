# 3타 R14 — 23·24번째 보라1단계만

개별투명PNG는`attack-03/native/`,4배확대는`attack-03/4x/`,검증/색별단계는`manifest.json`·`vfx-timing.csv`를따른다. GIF는각그림80ms의느린순서검토용이며54장decodedRGB일치를확인했다. 이후 사용자 승인에 따라 실제 Player의 3타 모션/검기에 연결했다. 현재 재생 시간·입력 정책과 Unity 실행 검증은 [GAME_SPEC 2.1.3](../../../../docs/GAME_SPEC.md#213-f-p03-구현확인과-sequence-diagram)을 따른다. 이 GIF의 느린80ms 간격은 게임 속도가 아니다.
