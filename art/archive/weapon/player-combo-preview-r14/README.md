# 3타 최종54포즈와 검기 노출

[전체54장](attack-03-all-frames.png) · [순서 확인 GIF](attack-03-preview.gif) · [원본 크기 개별 PNG](attack-03/native/)

사용자 확정은 1타1~24와2타16~45를 직접 연결한54포즈다. 몸체·검의 피벗·각도·시간·정렬을 유지하고 다음 순서로 검기를 표시한다.

| 순번 | 보라 | 파랑 |
| --- | --- | --- |
| 1~22 | 없음 | 없음 |
| 23~24 | 1단계 | 없음 |
| 25 | 1단계 | 1단계 |
| 26 | 2단계 | 1단계 |
| 27~29 | 2단계 | 2단계 |
| 30~32 | 3단계 | 3단계 |
| 33~35 | 마지막 잔광 | 마지막 잔광 |
| 36~54 | 없음 | 없음 |

포즈와 노출 메타데이터는 [manifest.json](manifest.json)·[vfx-timing.csv](vfx-timing.csv)에 있다. 편집 원본 검과 검기는 상위 weapon.aseprite와 [검기 작업실](../greatsword-vfx-edit/README.md)을 사용한다.

현재 Player의3타에 연결했다. GIF는 각 그림80ms의 느린 순서 확인용이며 실제 공격 속도는 [GAME_SPEC](../../../../docs/GAME_SPEC.md)의 F-P03을 따른다.
