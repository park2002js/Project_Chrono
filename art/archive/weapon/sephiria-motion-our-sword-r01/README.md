# 우리 검 × 세피리아 대검 1·2타 전체 프레임

2026-11-16. 사용자 요청에 따라 세피리아 대검의 위치·회전 곡선, 어깨/검/검기 피벗 간 거리와 검기 이미지·발생 시점·간격·크기를 그대로 사용하고 **검만 현재 Project_Chrono 이미지로 교체**했다.

- [1타 전체 30fps: F0~F18,19표본](attack-01-all-30fps.png)
- [2타 전체 30fps: F0~F22,23표본](attack-02-all-30fps.png)
- [1타 전체 60fps 보간: F0~F36,37표본](attack-01-all-60fps.png)
- [2타 전체 60fps 보간: F0~F44,45표본](attack-02-all-60fps.png)

개별 투명 PNG는 `attack-01/30fps/`, `attack-02/30fps/`, `attack-01/60fps/`, `attack-02/60fps/` 아래에 있다. 각 폴더의 `native/`는128×128px, `6x/`는768×768px이다. 총124표본×2배율=248개다. 전체 프레임 그림은3배로 표시하고 프레임 번호·시간·각도·손잡이 좌표를 붙였다. 빨강은 Player 원점, 초록은 Shoulder, 노랑은 검 손잡이, 하늘색은 검기 피벗이다.

각 배율은 같은 좌표식을 해당 해상도에서 최근접 샘플링한다. `6x`는 이미 회전해128px로 반올림된 결과를 확대하는 대신, 원본 Sprite를6배 공간에서 회전하므로 소수 좌표의 피벗을 더 세밀하게 표시한다.

## 사용한 현재 검

`art/archive/weapon/weapon.aseprite`의 첫 번째 검집째 스프라이트를 사용했다. 현재 게임의 `project/Assets/Art/Weapons/weapon.png` 첫7×29px 셀 `weapon_00`이며, 원본 Aseprite 첫 프레임의 레이어 합성과 전 픽셀이 같다. 과거 Detail R02 작업 폴더의 검을 가져오지 않았다.

- 16PPU, 크기 보정 없음
- 원본은 검끝 아래, 손잡이 피벗은 좌상단 기준(3.5,3.5)px
- 원작 위향 검에 맞춰 정확히180° 회전 후 손잡이는 좌상단 기준(3.5,25.5)px
- [현재 검 셀](source/our-sword-current.png), [위향 정렬 후 검](source/our-sword-pointing-up.png)
- 색·길이·폭·불투명 픽셀을 변경하지 않고 방향만 정렬

## 원작과 같게 둔 값

- `GreatSword_Attack1/2`의 p(t)·φ(t), 원본 키/접선과30/60Hz 평가값
- 위 조준 Shoulder=(2.5,8)px, 검 피벗은 원작 각 프레임 위치
- 검기 피벗=(2.5,24)px, 원본70×66px 이미지의 공통 피벗=(35,33)px
- 1타 검기 생성 F30=11(.366667초), 2타 F30=7(.233333초)
- 원본 검기4장, 20Hz 장당 명목50ms/전체200ms, 2타flipX
- 원본 검기 크기·반경과 검-검기 피벗 사이 거리. 검 길이가 달라 생기는 칼끝-검기 간격은 그대로 표시

## 조건과 확인

위쪽 조준·공격속도1·기본 사거리이며 Player 상대 좌표다. Player 몸체를 제외하고 검기 뒤에 검을 표시해 위치가 보이게 했다. **원작 Update 순서에 따른 실제 렌더 캡처가 아닌 정적 재구성**이다. 마지막 표본은 클립 종료 경계이며 한 프레임을 추가 유지하는 뜻이 아니다. FX의 실제 Update 양자화 한계는 [원작 분석](../../../../docs/archive/03_Analysis/Sephiria_GreatSword_Attacks_20261115.md)을 따른다.

`build_frames.py`는 원본을 읽어 재생성한다. 기존 Python3119/Pillow를 사용하며 새 의존성을 설치하지 않았다. `manifest.json`에는124표본의 위치·각도·FX 인덱스·파일 경로, 입력 SHA-256 및 검사 결과가 있다. 원본 검/native/Unity meta·참고 곡선의 변경 없음, 전체 이미지 잘림 없음, 원본 검기 픽셀·위치의 별도 합성 일치,30fps19/23·60fps37/45표본과248파일을 확인했다. 게임 코드·씬에는 적용하지 않았다.

독립 검토에서도8입력 해시·124표본과 원작 값 일치·검 원본/180° 정렬·248PNG 규격/RGBA/잘림·4비교판을 확인했다. 사용자 최종 모션 승인이나 Unity 실행 검증을 뜻하지 않는다.
