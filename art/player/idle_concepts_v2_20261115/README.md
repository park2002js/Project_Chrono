- `player-idle-comparison.png`: 번호별 12배 확대 비교표.
- `player-idle-size-check.png`: 1배 및 밝고 어두운 배경의 4배 표시.
- `player-idle-concepts.aseprite`: 20×20px, 디자인별 1프레임씩 총 6프레임. 재생용 Idle 애니메이션이 아님.
- `aseprite/`: 개별 편집 원본. 의상 / 머리 윤곽·머리카락 / 얼굴·귀의 3레이어.
- `png/`: 개별 20×20px 투명 PNG. 실제 폭12~15px·높이20px.
- `player-idle-sheet-120x20.png`: 20px 셀 6개가 가로로 이어진 시트.
- `concepts.lua`, `build-in-aseprite.lua`: 1px 단위 제작 원본과 Aseprite 작성·검사 스크립트.
- `validation.json`: 원본 재열기·PNG 픽셀 일치·규격·이진 알파·픽셀 연결 검사 결과.

두상의 기본 영역은 13px(전체의65%)이며 04의 묶음머리와 06의 긴 머리 끝은 아래로 이어집니다. 얼굴은 양쪽 눈을 같은 높이에 두고 오른쪽 귀와 뒤통수로 방향감을 표현했습니다. 무기·팔·손은 몸체에 그리지 않았습니다. 피부색은 얼굴·귀에만 사용했습니다.

참고 자료는 사용자가 제공한 Hunter `sheet.zip`의 Idle과 의상 이미지 2장입니다. Hunter는 눈·귀·뒤통수 배치만 참고했으며 원본 픽셀을 복사하거나 축소하지 않았습니다. `references/`의 Hunter 이미지는 비교용이며 결과 ZIP에는 포함하지 않습니다.

기술 검사 통과는 최종 디자인 선택이나 사용자의 미술 승인과 구분합니다. 이번 작업에는 다른 방향·애니메이션·Unity 연결이 포함되지 않습니다.
