# Project Chrono — 질문·확정 답변 요약

갱신: 2026-11-15 (Asia/Seoul). **Q1~Q29 모두 답변·통합 문서 반영 완료, 현재 답변 대기 없음.** 사용자 요청에 따라 반복 질문·폐기된 선택지·권고 문단을 압축했다. Q 번호는 기존 기록과 연결하기 위해 유지한다.

현재 사양 원본은 [GAME_SPEC](GAME_SPEC.md)이다. 아래 연결 ID는 그 문서의 클래스·기능 번호다. 상세 비교는 GAME_SPEC 3.1 ‘고민’, 선택 이유는 3.2 ‘결정’ 및 [선택 기록](archive/01_Choice/Notion_Answers_20261115.md), 후속 검토는 [비교·보류 기록](archive/02_Hold/Notion_Comparisons_20261115.md)을 따른다. 이유가 없는 선택에 새 이유를 붙이지 않으며, 현재안과 성능 검증 결과를 구분한다.

문서·비연출 로직 방향을 먼저 정하고, 케이스별 상세 API 흐름은 실제 코드 작성과 함께 만든다. 문서 반영은 Unity 구현·연결·검증 완료가 아니다. 원문 출처 N1~N4·L1~L2와 미채택 대안은 GAME_SPEC에서 추적한다.
