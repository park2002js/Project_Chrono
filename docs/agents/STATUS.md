# Project_Chrono 현재 상황과 인수인계

이 내용은 현재의 진행 상황 및 개발자 세부 요구 사항들을 기록하여, 다른 에이전트나 새로운 세션에서도 이전과 동일한 작업 환경 및 진행도를 갖추는 용도이다.

현재의 진행상황과 완료된 것들, 진행 중 상태에 놓인 미완 상태에 놓인 것들, 그리고 앞으로 남은 세부 과제들을 기록한다.
세부 과제란 앞으로 남은 모든 과제를 말하는 것이 아닌, 다음 단계의 과제를 이루기 위해서 해야 하는 세부 과제들을 의미한다.

과제가 완료되면 `/docs/notes`를 참고하여 다음 과제가 무엇인지 확인하여 갱신한다.

## 2. 맥락

시작 시 [AGENTS.md](../../AGENTS.md)를 읽고, 작성·설계 기준과 결정 배경은 [DESIGN.md](DESIGN.md)를 확인한다. 

### 계획
- 단계별 목표
  - 1차 캡스톤: 기본 조작을 배우는 튜토리얼과 첫 번째 보스 구간을 예상한다. 조작감과 전체적인 아트 분위기를 전달하는 것이 목표다.
  - 2차 PlayX4: 보스별 스테이지와 1차 최종 보스를 포함하는 데모 구간을 목표로 한다.
- 구현 확정하지 못한 부분
  - 계획서에는 시간·스택·보스라는 키워드, 시간 되돌리기, 속도 변화, 회피와 무적, 체크포인트 복원, 세이브·로드 등의 아이디어가 있다. 이번 문서화만으로 각각의 구현 범위·우선순위·자료구조·완료 조건을 확정하지 않았다. 작업 전 관련 범위를 확인한다.
