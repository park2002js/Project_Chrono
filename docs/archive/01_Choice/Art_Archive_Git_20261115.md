# 선택 주제
주제 : 아트 완성 결과물 보관과 작업 자료 Git 제외

# 선택 사안 1
- 선택 : 완성 결과물의 편집 원본과 필요한 출력물을 `/art/archive`에 대상별로 분류해 Git에 저장하고, 그 밖의 `/art` 하위 폴더는 로컬 작업 공간으로 유지함.
- 이유 : 작업에 사용한 자료가 계속 갱신되고 쌓여 GitHub 저장에 문제가 생김.
- 제시된 다른 선택 사안들 : 없음.
- 적용 : 명시적으로 최종 확정된 Title 로고 Aseprite와 PNG를 `art/archive/title/`에 복사함. 기존 작업 파일은 유지하고 다른 아트의 최종 승인 여부는 변경하지 않음.
