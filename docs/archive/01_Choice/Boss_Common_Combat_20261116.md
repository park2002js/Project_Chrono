# 선택 주제
주제 : F-B01~F-B06 공통 Boss 기반과 더미의 통합 검증
- 2026-11-16 사용자가 여섯 기능을 모두 구현하고 테스트 더미의 상속·임시 패턴·탄환별 발사·무작위/우선순위·Slash·그로기까지 확인하도록 요청했다. 현재 사양·실제 결과는 [GAME_SPEC](../../GAME_SPEC.md)의 2.2를 따른다.

# 선택 사안 1
- 선택 : 공통 기능을 실제 더미 프리팹과 임시 패턴으로 연결하고 이후 콘텐츠 작업이 패턴 추가에 집중할 수 있는 상태까지 검증
- 이유 : 사용자가 다음 작업을 개별 패턴 추가로 이어가기를 원함
- 제시된 다른 선택 사안들 : 별도 제안 없음
- 적용 : 실제 Character→BossCharacter→DummyBoss, BossPattern 파생, 일반/금색/레이저/장판의 Projectile 상속을 확인한다. 조우·전투·중단·사망·재도전과 저장·문·표시를 포함하며 경비 로봇의 F-B07 고유5패턴을 더미로 완료 처리하지 않는다.

# 선택 사안 2
- 선택 : 기존 Q17·Q25·Q27·Q28의 조우 완료 순서·100즉시 그로기·직전 제외/가중·기존 위험물 유지·접촉 피해 없음 적용
- 이유 : 이미 확정된 공통 전투 규칙을 따른다는 구현 판단
- 제시된 다른 선택 사안들 : 별도 제안 없음
- 구현 조정 : 더미의 HP50%·거리·선행 사용 횟수·우선값10과 시간·피해·가중 수치는 검증 예시이며 실제 경비 로봇 밸런스 확정이 아니다. 같은 양수 우선순위끼리는 가중 추첨하고 직전 제외를 우선한다. 조우/사망의 시간 기반 카메라 연출·색/범위 표시는 최종 미술 전의 교체 지점이다.
- 경계 : 그로기는 현재 패턴만 취소하고 이미 생성한 위험물은 유지한다. 사망·재도전·세션 종료는 소유 위험물을 정리한다. 처음 조우한 기록은 연출 완료 후, 처치 기록은 사망 사건에서 저장 요청하며 외부는 디스크 기록 완료를 기다리지 않는다.
