# 선택 주제
주제: 보스 6종의 탑다운 정면 픽셀 디자인
- 2026-11-16 사용자가 직접 그린 6종의 스케치 PDF와 Notion의 ‘적 컨셉’ 레퍼런스를 바탕으로 Aseprite 정면 이미지를 제작하도록 요청했다.

# 선택 사안 1
- 선택: 보스는 8방향을 가지며 Player가 있는 쪽을 바라본다. 이번 제작 대상은 6종 각각의 탑다운 정면 픽셀 이미지다.
- 이유: 바라보기와 공격 방향이 자연스럽게 느껴지도록 하려는 사용자 설명.
- 대부분 Player보다 크거나 약간 크게 만들고, 거대 로봇·샌드웜 등의 모티브를 따른다. 디테일은 간략해도 되며 색·외형·크기는 지정 레퍼런스를 검색해 참고한다.
- Aseprite 지정 자체의 별도 이유는 미기록. 다른 선택지 비교 요청은 없었다.
- 팔레트·거대형의 정확한 픽셀 치수는 AI 제작안이며 사용자 최종 선택이 아니다. 정면 제작과 나머지 방향/전투 콘텐츠 구현은 구분한다. 현재 파일·검증·남은 작업은 [GAME_SPEC 3.3.12](../../GAME_SPEC.md#3312-보스-6종-탑다운-정면-시안--front-r01)을 따른다.

# 선택 사안 2 — 꽃의 2D 제작 제외
- 선택: 꽃은 픽셀 제작 대상에서 제외한다.
- 이유: 원래3D 모델을 import하여 구현하려던 대상이라는 사용자 정정.
- R01 꽃 그림은 과거 제작 이력이며 현행 자산으로 채택하지 않는다.3D 모델 도입·연결 완료를 뜻하지 않는다.

# 선택 사안 3 — 경비 로봇 형태와 크기 수정
- 선택: 검정·흰색 경찰 색상과 머리 위 빨간 사이렌, 둘레 장식 없이 박힌 어깨 수정, 총구로 읽히는5개 구멍, 상체만 바닥에 붙는 평평한 밑면으로 바꾼다. 주먹의 손등은 바깥 왼쪽/오른쪽을 향하고 수정이 일부 노출되게 한다.
- 선택: 몸체는 기존의1.5배, 주먹은 Player의2배 크기로 키운다.
- 이유: 기존의 낮은 픽셀 크기에서는 디테일 표현이 부족하다는 사용자 판단. 바닥 부착형 상체의 불필요한 돌출물은 제거한다.
- 제작에서는 몸체의 가로/세로 약1.5배와 주먹 높이40px=Player20px의2배로 적용했다. 세부 픽셀 배치의 최종 미술 선택과 구분한다.

# 선택 사안 4 — 군용 로봇의 색·입체감·크기 수정
- 선택: 군용 국방색, 몸체에 비해 조금 작은 등 수정, 입체 직육면체로 읽히는 머리로 바꾸고 크기를1.5배로 키운다.
- 이유: 이유 미기록.
- 몸체 확대와 수정의 상대 크기 축소를 구분하며 실제 규격·확인 결과는 GAME_SPEC3.3.12를 따른다.

# 선택 사안 5 — 뱀의 침식·마력선·부피 구분
- 선택: 수정이 있는 마디는 검정·보라 침식을 강하게 표시하고, 다른 밝은 마디에는 실처럼 가는 보라 마력선을 사용한다. 마디의 세로 부피를 늘리고 잔가지 같은 전기 장식을 모두 제거해 외곽을 정리한다.
- 이유: 납작한 마디의 부피감과 수정 보유 여부에 따른 외형 구분을 개선하려는 수정 요청.
- 동일8마디의 구분은 유지하며 픽셀 치수·침식3/밝은5 배치는 제작 결과로 기록한다.

# 선택 사안 6 — 연구자 기본형 후 머리·가운 흩날림
- 선택:30×30px의 일반 남성·흰 연구복 기본형을 먼저 만들고 머리와 가운이 흩날리는 모습을 추가한다. 손이 필요하면 단순한 정사각 형태로 표현한다.
- 이유: 기본형을 먼저 정리한 뒤 흩날림을 추가하려는 사용자 요청. 별도 이유는 미기록.
- 기본1장과 흩날림6장을 분리했다. 피부색3×3 손·1~2px 변화·180ms×6 루프는 제작안이며 최종 게임 애니메이션 시간으로 확정하지 않는다. 현재 원본과 검증·남은 작업은 GAME_SPEC3.3.12를 따른다.

# 선택 사안 7 — 군용 로봇 좌우 대칭·혼합색
- 선택: 군용 로봇을 좌우 대칭으로 만들고 단색 인상이 들지 않도록 중간에 다른 색을 섞는다.
- 이유: 이유 미기록.
- R03에서는 국방색 중심에 모래색·청회색·어두운 적색을 부품별로 배치하고 형상·색·알파를 정확히 대칭으로 맞췄다. 구체적인 색 배치의 최종 미술 선택과 구분한다.

# 선택 사안 8 — 첨부 이미지 단위의 뱀 마디
- 선택: 첨부한 이미지의 크기를 단위로 삼아 현재 뱀 색상을 부여하고 마디를 구성한다.
- 이유: 현재 뱀 모습이 아쉽다는 사용자 피드백. 구체적인 선택 이유는 미기록.
- 첨부의 실제 크기는27×27px이다. R03에서 윤곽·면 구성과 알파까지 복제한 것은 AI의 해석 오류이며 사용자 승인 사항이 아니다. 사용자는 크기만 참조하라는 뜻이었다고 정정하고 R03 복제안을 거절했다. 현행 요청은 선택 사안10과 GAME_SPEC3.3.12를 따른다.

# 선택 사안 9 — 경비 사이렌 제거·총구 상승
- 선택: 경비 로봇 머리의 빨간 장식을 제거하고 총구 앞부분을 약2px 위로 들어 올린다.
- 이유: 총구가 굽어진 것처럼 보이는 인상을 없애려는 사용자 요청. 빨간 장식 제거의 별도 이유는 미기록.
- R03은 사이렌과 받침을 제거하고 뒤 장착부를 고정한 채 앞 입구 중심을2px 올리고 관 길이를2px 줄였다. 다른5레이어는 보존했으며 검증·현재 원본은 GAME_SPEC3.3.12를 따른다.

# 선택 사안 10 — 뱀 첨부는 크기만 참조
- 선택: 첨부 이미지는27×27px 크기 기준으로만 사용하고 뱀 마디 디자인은 새로 그린다. 기존 밝은 일반 마디와 검보라 수정 마디의 색상 구분을 유지한다.
- 이유: 첨부 디자인을 복제하라는 요청이 아니었다는 사용자 정정.
- R04의 볼록한 장갑·등판 이음선·하단 테두리는 새 제작안이며 사용자 최종 미술 선택과 구분한다. R03 복제안은 거절된 이력으로 보존하며 실제 파일·검증은 GAME_SPEC3.3.12를 따른다.

# 선택 사안 11 — 경비 손가락 수 수정
- 선택: 경비 로봇 각 손을 손가락3개와 엄지1개로 표현한다.
- 이유: 기존 손가락 수가 너무 많다는 사용자 피드백.
- R04에서는 양손34×40px 크기와 외곽을 유지하고 손 내부만 수정했다. 다른4레이어를 보존했으며 검증·현재 원본은 GAME_SPEC3.3.12를 따른다.
