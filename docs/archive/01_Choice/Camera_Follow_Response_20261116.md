# 선택 주제
주제: 일반 추적과 컷씬 타깃 전환의 카메라 접근 시간
- 현재 카메라와 세피리아의 추적 반응을 비교한 뒤 사용자가 접근 시간 변경을 요청했다.

# 선택 사안 1 — 90% 접근 약0.25초 적용
- 선택: 2026-11-16 사용자는 직전 비교에서 제시한 목표90% 접근 시간을0.25초로 변경하고 컷씬 타깃 변경에도 같은 설정이 적용되는지 확인하도록 요청했다.
- 이유: 비교 후 사용자 요청, 별도 이유 미기록.
- 적용: 기존 SmoothDamp 방식은 유지하고 내부 FollowDuration을0.5에서0.1283으로 변경한다. 정지 목표·초기속도0·맵 경계 제외에서90% 접근 약0.25초를 맞추는 기준값이다. 내부값0.25를 넣거나0.25초 뒤100% 도착하는 타이머로 해석하지 않는다.
- 범위: 일반 Follow와 CutsceneController의 Boss 타깃 전환/원래 대상 복귀가 같은 설정을 공유한다. Follow는 목표를 바꿀 때 속도를0으로 정리하며 실제 시간으로 진행해 컷씬 정지 중에도 접근한다. 생성/재배치의 snap=true와 Draw의 직접 위치 적용은 유지한다. 컷씬 전체 길이·줌·원작 임시 타깃 계수4는 변경하지 않는다.
- 근거·결과 원본: [카메라 비교8절](../03_Analysis/Camera_Follow_Sephiria_Comparison_20261116.md), GAME_SPEC의 U06·F-U04와 F-B02 기록을 따른다. 수식 비교와 실제 Unity 실행 결과를 구분한다.
