# 선택 주제
주제 : 제출 전 비상 운영 체제로 전환
- 결정 출처: 2026-11-14 사용자 요청. 요청 시점에 작품 제출까지 약 40시간이 남았으며 현재 결과물이 반쪽짜리 계획에 가깝다고 설명함.
- 현재 방침은 [AGENTS.md](../../../AGENTS.md), 양식은 [DESIGN.md](../../agents/DESIGN.md), 작업 순서는 [PLANS.md](../../agents/PLANS.md)를 원본으로 관리함.

# 선택 사안 1
- 선택: 계획 문서 통합·확정 → 코드 완성 → Sprite 추가 → 디버깅·리뷰 반복 순으로 진행하며 이에 맞춰 에이전트 행동 방침을 갱신함.
- 이유: 제출까지 남은 시간이 짧고 사용자가 의도한 기획의 구현과 이후 결과 보고서 작성을 함께 가능하게 해야 함.
- 제시된 다른 선택 사안들: 별도 대안 비교 없이 사용자가 위 전환을 직접 요청함.

# 선택 사안 2
- 선택: 산개한 기획의 충돌과 필수 누락은 별도 질문지 및 채팅 목록으로 모아 답변받고 통합 문서에 반영함.
- 이유: 상충하는 과거·현재 결정이 있어 사용자가 의도하는 버전 및 아직 정하지 못한 내용의 확인이 필요함.
- 제시된 다른 선택 사안들: 즉답 가능한 한두 질문은 채팅에서 바로 확인할 수 있음.

# 선택 사안 3
- 선택: 실제 아트가 필요한 부분을 제외한 확정 기능은 코드 단계에서 완성하고 도구 지원 버전을 근거로 Unity 버전을 정하며 레퍼런스는 작은 싱글 플레이 보스 러시 범위에 맞춰 활용함.
- 이유: 에셋 추가 후 조정·연결 작업을 최소화하고 필요한 도구와의 호환성을 확보하며 고정 무기·고정 능력인 게임에 불필요한 규모의 시스템을 들여오지 않기 위함.
- 제시된 다른 선택 사안들: 특정 Plugin·asset·Unity 버전은 아직 선정하지 않음.
