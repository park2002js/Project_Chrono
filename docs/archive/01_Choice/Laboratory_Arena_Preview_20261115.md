# 연구소 전투방의 크기 비교 기준
주제 : 연구소 실험실을 주 무대로 사용할 때 기존 Player와 비교해 공간의 크기·비율을 판단하기 위한 임시 배치 제작.
- 2026-11-15 사용자가 Enter the Gungeon의 보스방·출입문을 검색하고 바닥·벽·문 반복 패턴으로 사각형 임시 전투 공간을 만들도록 요청함.
- 현재 사양과 제작·확인 결과의 원본은 [GAME_SPEC 3.3](../../GAME_SPEC.md#33-연출아트-요구와-정의-순서)에 둠.

- 선택 : 원본1픽셀을 화면6×6픽셀로 표시함.320×180 원본을1920×1080으로6배 확대함.
- 이유 : 기존 플레이어를 배치한 실제 화면 구도를 보고 무대 크기를 비교하려는 목적.6×6 해석의 별도 이유는 미기록.
- 제시된 다른 선택 사안 : 반복 타일 한 장의 원본 크기를6×6픽셀로 만드는 해석. 사용자 답변으로 이 해석을 사용하지 않음.

# 선택 사안 2 — 연구소의 진행 방향

# 제작 시안과 미확정 사항
- 최초 AI 제작 시안 : 동일한 Player 크기를 유지한 세 가지 사각형 방을 한 화면에 모두 배치함. 후속 사용자 피드백으로 공간이 너무 작다는 점을 확인하여 R02 확대안으로 수정함. 이전 제작물은 이력으로 보존함.
- 방 크기·비율·색·벽 높이·문 폭은 최종 사용자 확정이 아님. 비교 결과에 따라 조정함.
- 전투 중 아래 입구 폐쇄와 처치 후에도 아래 문을 닫아 두는 표시는 시안이며, 이번 사용자 요청의 새 확정 규칙으로 확대하지 않음.
- 보스 크기·전투 판정·카메라 이동과 Unity 연결은 별도 확인이 필요함. 정적 비교 화면을 게임 기능 완성으로 기록하지 않음.

# 선택 사안 3 — 전체 원본과 플레이 시야 분리
- 선택 : 방 전체가1920×1080 안에 들어올 필요는 없으며 가장자리가 잘려도 됨. 전체 원본은1픽셀 기준1배로 확인하고 플레이 구도는 원본 일부를6배 확대한1920×1080으로 비교함.
- 이유 : 확대 화면의 목적은 방 전체를 보여주는 것이 아니라 실제 플레이 경험을 가늠하는 데 있음. 최초 시안의 방은 너무 작았음.
- 제시된 다른 선택 사안 : 최초 제작에서 적용한 전체 방을320×180 원본 화면에 모두 넣는 방식. 이번 후속 요청으로 현재 비교 기준에서 제외함.
- AI 시험 배치 : R02의512×288px 바닥과544×352px 전체 캔버스, 입구/중앙/출구 시점은 비교용 제안값이며 사용자 최종 크기 확정은 아님.

# 선택 사안 4 — ETG 보스맵의 정밀 분석 기준
- 선택 : 사용자가 지정한 `/art/environment/ETG-Boss-Maps`에서 타일 구성, 입구/출구, 바닥과 벽의 반복·두께, 방 크기 및 화면 너비 비율을 분석하고 Chrono 제작에 적용할 수 있도록 환산함. ETG1px→4×4px, Chrono1px→6×6px, 화면1920×1080을 기준으로 함.
- 이유 : 기존 AI 제작이 의도한 보스맵 구성을 충분히 반영하지 못해 대표 레퍼런스의 구체적인 공간·반복 규칙을 먼저 파악하려는 요청임.
- 제시된 다른 선택 사안 : 없음. 새로운 픽셀 배율이나 전체방 맞춤 표시를 제안하지 않음.
- 분석 결과의 원본 : [GAME_SPEC 3.3.1](../../GAME_SPEC.md#331-etg-보스방-분석과6배-픽셀-제작-기준). 같은 셀 수를6배로 표시하는 것과 원작 화면/방 비율을 보존하는 것은 서로 다른 결과임을 구분함.
- AI 제작 제안 :26×18셀·416×288 원본px는 중앙2셀 문의 대칭과 원작에 가까운 시야 비율을 위한 권고안이며 사용자 최종 크기 결정이 아님. 원작16px 모듈을 보존할 때 모든 세부 요소의 화면 크기까지 같아지는 것은 아님.
- 확인 한계 : 원본 자료는 정적 재구성, 실행 화면 관찰은 없음. 이번 작업은 분석·제작 기준 정리이며 새 맵·Unity 제작은 수행하지 않음. R02 실제 파일은 이번 확인 시 부재하여 기존 치수 기록만 비교함.

# 선택 사안 5 — 시야 비율 환산 후 균일 셀 우선
- 경위 : 사용자가 최빈 직사각형 ETG 방의 시야/방 비율을 우리 게임에 적용하여 방·셀·타일 크기를 정한 뒤, 크랙이 섞인 흰 실험실을 제작하도록 요청함. ETG38×27셀·608×432px와480×270 시야를 기준으로 Chrono320×180 시야에 필요한 정확한 바닥은405⅓×288px임.
- 선택 : **균일 셀 우선:400×288px,16px 셀25×18칸**. 사용자 선택지 응답을 받음.
- 이유 : 균일 셀 우선이라는 선택 기준을 명시함. 그 외 이유 미기록.
- 제시된 다른 선택 사안 : 비율 우선405×288px·10/11px 셀을3칸마다32px로 묶는 방식(폭 오차0.082%). 채택하지 않음.
- 수용한 차이 : 선택한 방은 이론 폭보다1.315789% 작고, 가로 시야가ETG78.947368% 대신80%(+1.052632%p)임. 세로62.5%는 같음. 이전416×288px 권고를 현재 기준으로 사용하지 않음.
- 흰 실험실 제작 요구 : ETG의 반복 바닥·방향별 벽·문 구조를 참고하고, 바닥에 중간중간 크랙을 넣어 반복되면서 단조롭지 않게 함. 기존 아래 입장/위 퇴장과1px→6×6px를 유지함.
- AI 제작값 :28타일·18크랙·벽 높이/문틀 크기·색·세부 배치는 요청에 따른 제작 결과이며 사용자가 각각 독립적으로 선택한 수치로 기록하지 않음. 상태별 문 그림은 게임 로직 확정과 구분함.
- 현재 결과 : [GAME_SPEC 3.3.2](../../GAME_SPEC.md#332-흰-실험실-etg-r03--균일-셀-선택과-실제-제작). 아트·Aseprite·정적 검사 완료, Unity 적용·플레이 확인 미실행.
