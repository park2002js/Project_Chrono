# 선택 주제
주제 : F-P03·F-U07의 공격·적중·타일 발소리와 적중 섬광
- 2026-11-16 사용자는 음원이 없어 Sephiria 자료를 사용하고, 공격으로 피해를 입힌 대상에 원작의 가느다란 직선 섬광을 넣도록 요청했다. 원작 Bank 두 개에서 필요한 음원을 추출하는 방법과 FMOD 도입 여부를 확인했다.

# 선택 사안 1 — Unity 내장 오디오
- 선택 : 필요한 음원을 추출한 뒤 Unity 내장 AudioSource로 연결
- 이유 : 별도 이유 미기록. 사용자는 FMOD 사용의 효율을 질문한 뒤 이 선택지로 답변했다
- 제시된 다른 선택 사안 : 기존 Q22의 FMOD 학습 목적에 따라 미들웨어 연결
- 범위 : 현재 공격·적중·발소리의 재생 방식. 과거 FMOD 학습 선택은 이력으로 보존하며 패키지를 설치하지 않는다

# 선택 사안 2 — 콤보별 소리
- 선택 : 콤보1=A, 콤보2=B, 콤보3=A 직후 B 재생
- 이유 : 사용자가 콤보별 표현을 직접 지정. 추가 이유 미기록
- 적용 : 기존 검기 생성 시점에 소리를 연결하며3타는 첫 휘두르기 F23과 두 번째 휘두르기 F25에 A→B 재생. AS1에서 간격은2/60초이며 A 파일의 재생 종료를 기다리지 않는다
- AI 적용 선택 : 원작 기본 대검1·2타는 같은 attackSwish07을 사용하므로 A=07, B=같은 계열의 별도06으로 구분. 적중은 CrashSlice 이벤트의11개 연결 표본 중 hitSlash01 하나, 발소리는 footstepRoad의3개 표본을 선택. 원작 전체 Material·3D·gain·pitch 라우팅을 복제한 것은 아니다

# 선택 사안 3 — 실제 적중 섬광
- 선택 : Sephiria의 SwordSlashFx7장과 실제 성공 타격의 접점·수직 방향 규칙을 현재 일반 공격에 적용
- 이유 : 사용자가 공격 방향의 수직 부근으로 발생하는 원작 피드백을 분석하고 구현하도록 요청
- 범위 : 실제 피해를 받은 캐릭터·구조물에만 적중음과 섬광 생성. 원작 Block 분기는 현재 게임에 대응 상태가 없어 추가하지 않는다
- AI 적용 선택 : 게임 시간 기준20Hz·명목0.35초, 접점 반경0.2와 수직±10도, 월드 위치 고정. 원작의 프레임 지연 시 초과시간을 버리는 Timer 대신 절대 경과시간으로 재생하며 실제 재질에 없는 `_Intensity` 효과를 새로 만들지 않는다
- 실행 후 보정 : 우리 zero-distance BoxCast가 작은 수신 충돌체 바깥의 좌표를 반환하는 것을 실제 관측해 `collider.ClosestPoint(rawPoint)`로 수신 범위에 붙인 뒤 위치 오차를 적용한다. 원작 CircleCast의 raw 접점 전달과 구분하며, 피해 콜백 전에 보정 좌표·각도를 보존한다

# 초기 튜닝과 검증의 구분
- 공통 음량0.8·발소리 추가 배율4·걷기 간격1.2는 AI가 연결한 초기값으로 사용자 최종 청감 승인이 아니다. 작은 원본 발소리를 보정하며 기존 조정값은 Editor 재적용 때 유지한다
- 원본·추출 근거는 [음원 아카이브](../../../art/archive/audio/player-feedback-r01/README.md), 섬광은 [분석](../03_Analysis/Sephiria_Melee_Hit_Feedback_20261116.md)을 따른다
- 실제 코드·연결·검증의 현재 상태는 [GAME_SPEC](../../GAME_SPEC.md)의 F-P03·F-U07을 따른다. 이 선택 기록만으로 실행 완료를 주장하지 않는다
