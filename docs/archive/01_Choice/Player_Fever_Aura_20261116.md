# 선택 주제
주제 : F-P11 Player 각성 상태의 황금 오라 표현
- 2026-11-16 사용자는 Player가 각성 상태일 때 몸에서 황금색 오라가 피어오르는 VFX를 요청했다

# 선택 사안 1 — 상태와 표현 연결
- 선택 : 실제 각성 중 황금 오라 표시
- 이유 : 사용자가 상태의 시각 표현을 직접 요청. 추가 이유 미기록
- AI 구현 선택 : CharacterBuff의 실제 false→true/true→false 전환 알림에 FeverAuraFx가 구독한다. 재획득은 기존 기간만 갱신하며 입자 재시작·새 오브젝트 생성 없이 유지한다
- 적용 범위 : 기존 각성 수치·다음 프레임 적용·Remove 우선·기간 갱신은 유지. 다른 효과나 각성 음향은 추가하지 않는다

# 선택 사안 2 — 황금빛 상승 표현
- 선택 : 몸에서 위로 피어오르는 황금색 오라
- 이유 : 사용자가 색과 진행 방향을 지정
- AI 제작 선택 : 몸 뒤의 가는 금빛 불길과 앞쪽의 작은 불씨를 Unity ParticleSystem으로 구성한다. 재생은 게임 시간에 맞춰 정지하고 Player와 함께 이동하며 해제·사망·비활성화 때 잔여 입자를 정리한다
- 초기 색·크기·방출률·수명은 제작 초기값이며 사용자 최종 미술 승인과 구분한다. 원작 CharacterBuff·ElementalParticle의 loop 수명 책임을 참고하되 원작의 특정 오라 색·궤적·수치를 그대로 복제한 것으로 기록하지 않는다
- Player 전체 재활성은 현재 IsFever를 한 번 동기화한다. Buff 컴포넌트만 비활성화해 IsFever가 유지되는 기존 계약에 별도의 숨김이나 매 프레임 조회를 추가하지 않는다

# 현재 상태
- 첫 기능 검사는 통과했지만 AI 시각 검토에서 불길이 몸에 가려 발 주변만 보이는 것을 확인해 발생 폭·상승·크기·밀도를 재조정했다. 최종 Player 프리팹 연결·격리11검사와 실제 정지/이동 화면을 확인했으며 사용자 최종 미술 승인과 구분한다
- 코드·자산·실행 확인의 현재 상태는 [GAME_SPEC F-P11](../../GAME_SPEC.md#2111-f-p11-고정-효과갱신제거그로기)을 따른다
