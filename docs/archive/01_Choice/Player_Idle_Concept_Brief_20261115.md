# 선택 주제
주제 : Player 정면 Idle 픽셀 시안의 제작 조건
- 출처: 2026-11-15 사용자 직접 요청 및 첨부 레퍼런스 4장(Enter the Gungeon 크기 비교, Sephiria Pink Rabbit Idle, 검사 의상 이미지 2장).
- 사양 원본: [GAME_SPEC 3.3](../../GAME_SPEC.md). 본 기록은 선택 이유와 최종 디자인의 미확정 상태를 남김.

# 선택 사안 1
- 선택 : Aseprite로 20×20px 이내 정면 Idle 시안을 5종 이상 제작. 캔버스를 억지로 채우지 않고 자연스러운 인간형 폭을 유지함.
- 이유 : Aseprite로 픽셀 제한을 강제하기 위함. 20px 상한 자체의 선택 이유는 미기록.
- 제시된 다른 선택 사안들 : 없음.

# 선택 사안 2
- 선택 : 여성 인간형 동양풍 검사, 흑백 계열, 머리가 전체 높이의 약 2/3.
- 이유 : 큰 머리는 플레이 중 캐릭터를 확인하기 쉽게 하기 위함. 성별·흑백·동양풍의 선택 이유는 미기록.
- 제시된 다른 선택 사안들 : 제작한 01~06은 AI 디자인 제안이며 사용자 최종 선택은 아직 없음.

# 선택 사안 3
- 선택 : 몸체에 무기·팔·손을 그리지 않음.
- 이유 : 무기가 360도 자유롭게 회전하며, 별도 손 점을 움직이거나 잡는 모습을 생략할 예정이기 때문.
- 제시된 다른 선택 사안들 : 별도 손 점 / 손 생략. 사용자 설명에 두 가능성이 있으며 이번 시안에서 구현 방식을 최종 선택하지 않음.

# 제작 결과와 남은 선택
- Aseprite 원본 및 투명 PNG 6종을 제작함. 결과·검사 근거·원본 링크는 GAME_SPEC 3.3을 따름.
- 최종 시안 선택, 후면·측면 및 애니메이션 제작, 게임 내 크기·피벗·Unity 연결은 아직 수행하지 않음.

# 선택 사안 4 — 6종 비교 후 R01 수정 방향
- 선택 : 04번 머리를 기준으로 실제 높이20px, 06번 옷을 입히되 좌우 대칭 느낌, 겉옷을 망토처럼 흩날릴 수 있는 형태로 구분.
- 이유 : 겉옷과 안옷의 구분 및 대칭 느낌을 원함. 04/06 조합과 높이20px를 선택한 추가 이유는 미기록.
- 제시된 다른 선택 사안들 : 최초 01~06. 사용자가 04+06 조합의 수정 방향을 직접 지정함.
- 반영 : [GAME_SPEC 3.3](../../GAME_SPEC.md) 및 `/art/player/idle_revision_01/`. Aseprite R01 제작·검수 완료. 위 '최종 시안 선택 미수행'은 최초 6종 전달 시점의 상태이며, 현재는 조합·수정 방향 선택 완료, 수정 이미지 자체의 최종 승인은 아직 없음.

# 선택 사안 5 — 정면에서 왼앞3/4 시안으로 변경
- 선택 : 정면 대신 중심에서 왼쪽을 바라보는 시안 약10종. 게임의 몸체4방향은 왼앞·오앞·왼뒤·오뒤.
- 이유 : 첨부 ETG처럼4방향으로 나타낼 예정이기 때문. 정면 R01을 현재 방향 기준으로 사용하지 않음.
- 제시된 다른 선택 사안들 : 이전 정면 R01. 사용자가 직접 방향을 수정했으며 최신10종 중 최종 디자인은 아직 선택하지 않음.
- 반영 : [GAME_SPEC 3.3](../../GAME_SPEC.md), `/art/player/idle_leftfront_concepts_10/`의 왼앞3/4 후보10종. 의상 자체의 대칭 느낌과 큰 머리·백발·흑백·분리 망토·팔/손/무기 없음 조건을 유지하고, 원근 때문에 보이는 픽셀 면적은 비대칭으로 제작함. 다른3방향·애니메이션·Unity 적용은 아직 없음.

# 반려 기록 — 최초 왼앞10종
- 사용자 반응 : "실제 각도가 아니야. 완전히 다 깨져버렸잖아."
- 이유 : 사용자가 의도한 각도가 아니며 형태가 깨졌다고 판단함. 이전 AI의 시각 검수 통과 판단은 철회함.
- 반영 : GAME_SPEC·STATUS·PLANS에 반려 상태와 기술 검사/미술 판단의 차이를 기록함. `/art/player/idle_leftfront_redraw_02/`에10종을 새로 그림. 이 재작성안도 사용자 승인·최종 채택 상태는 아님. 이전 파일은 이력으로 보존하며 승인된 기준으로 재사용하지 않음.

# 별도 새 요청 — 정면 얼굴과 옆 귀·뒤통수의 V2 시안
- 선택 : 여성 인간형 동양풍 검사·흑백 계열·20×20px 이내·머리 약2/3·팔과 무기 생략을 유지하며, 얼굴은 정면이고 귀와 뒤통수 일부가 옆에 보여 방향감이 느껴지는 Idle 시안5종 이상을 Aseprite로 제작 요청함.
- 이유 : 큰 머리는 식별성, 팔·손 생략은 무기의360도 독립 회전을 위한 것임. 귀·뒤통수 배치는 Enter the Gungeon의 표현을 참고하도록 명시함.
- 제시된 다른 선택 사안들 : 새01~06은 AI 디자인 후보이며 사용자 최종 선택이 아님. 이번 범위에서 기존 게임4방향 정의를 바꾸지 않음.
- 반영 : [GAME_SPEC 3.3](../../GAME_SPEC.md) 및 `/art/player/idle_concepts_v2_20261115/`. 사용자 제공 Hunter ZIP의 Idle과 첨부 의상 이미지2장을 실제 확인함. 새6종의 제작·검사와 최종 미술 승인·게임 적용을 구분함.
