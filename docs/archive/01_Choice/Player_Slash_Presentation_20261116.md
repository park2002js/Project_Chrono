# 선택 주제
주제: F-P07 Slash의 발도·카메라·음향·공간참 연출 순서와 조정 방식
- 출처: 2026-11-16 사용자 대화. 기존 Slash의 줌이 빨리 끝나고 확대와 애니메이션 시점이 의도와 다르지만 원하는 감각을 수치로 표현하기 어렵다고 설명한 뒤, 장면의 순서를 직접 지정했다.
- 현재 사양·구현·검증 상태의 원본은 [GAME_SPEC 2.1.7](../../GAME_SPEC.md#217-f-p07-slash-입력전용-연출한-번-판정)에 둔다.

# 선택 사안 1 — 장면을 기준으로 한 Slash 연출
- 선택: Slash 입력 직후 빠르게 줌 인한다. 느린 줌 인으로 넘어갈 때에는 Player가 이미 칼을 일부 꺼낸 발도 자세에 도달해 있으며, 그 자세를 잠시 유지한다. 느린 줌 인 구간에서 약0.7초 뒤 노출된 칼날 중앙에 빛나는 VFX가 나오고, 이어 칼을 완전히 넣는 구간만 재생한다. 칼이 닫히는 순간 “탁” 소리를 내며 카메라를 원래 배율로 복귀시킨다. “탁”에서 약0.5초 뒤 Line의 Slash 효과음과 함께 그 Line을 기준으로 UI를 제외한 게임 화면이 공간참처럼 어긋나는 연출을 실행한다.
- 이유: 기존 줌의 짧은 지속·확대 감각·애니메이션 타이밍이 사용자 의도와 달랐다. 사용자가 원하는 흐름을 장면 단위로 직접 설명했다.
- 제시된 다른 선택 사안들: 별도의 경쟁 연출안은 제시되지 않았다. 기존 단일 대기 종료 후 즉시 줌 복원·검격 flash 순서는 이번 요청의 대상이다.
- 수치 상태: 약0.7초와 약0.5초는 사용자가 변경 가능하다고 밝힌 초기 조정값이다. 빠른/느린 줌 구간의 길이·전환점·확대 정도도 조절할 수 있어야 하며 최종 감각 확정으로 기록하지 않는다.
- 아트 기준: 발도는 기존 사용자 선택 R02를 사용하며 R01·R03을 다시 채택하지 않는다. 신규 VFX·음향의 제작/연결과 최종 미술·청감 승인은 구분한다.

# 선택 사안 2 — 실제 전투 판정과 해제 시점
- 선택: 사용자 후속 답변으로 **납도 “탁” 후 지연이 지나 공간참·Slash 효과음이 발생하는 순간** 실제 피해·탄 제거를 판정하고 전투 시간·조작을 해제한다.
- 이유: 이유 미기록
- 제시된 다른 선택 사안들: 납도 “탁” 순간에 판정·해제하는 안. AI 권고는 지연 공간참 순간이었으며 사용자 후속 답변으로 그 시점을 확정했다.
- 수치 구분: 빠른 줌0.18초·칼날 빛0.12초·납도0.16초·줌 복귀0.18초 및 빠른/최종 직교 크기3.2/2.8은 AI의 초기 제작값이다. 사용자 대략값인 유지0.7초·공간참 지연0.5초와 함께 조정 가능하며 최종 감각 확정이 아니다.

# 선택 사안 3 — 시전 중 Line 유지와 공간참 순간 노란 피해 경로
- 선택: Slash 시전 전 맵에 보이던 Line은 발도·줌·납도·공간참 지연 연출 동안에도 같은 맵 위치에 계속 표시한다. 실제 공간참 순간 그 선이 사라지는 자리에 노란 선과 명확한 절단 경계를 표시해 피해가 발생하는 경로를 알아볼 수 있게 한다.
- 이유: 사용자가 Slash를 시전하면 기존 Line이 보이지 않는 문제를 지적했고, 공간이 어긋나는 화면 속에서도 그 경로에 피해가 발생함을 명확히 알리고자 했다.
- 후속 사용자 정정: 초기 검증 캡처를 본 사용자는 “노란색 선 역시 vfx여야” 하며 틈이 벌어지는 것이 아니라 “단절된 공간에 걸쳐있는” 표현이어야 한다고 명시했다. 시전 중 기존 Line 유지 요구는 유지한다.
- 반려된 AI 제작안: 불투명 solid gold core와 어두운 외곽으로 피해 범위를 칠한 막대 표현. 기술 검사를 통과했어도 사용자가 원하는 검격 VFX로 승인된 것이 아니며 현행에서 제외한다.
- 현재 AI 제작안: 어긋난 월드 위 원래 Line 경로에 걸친 황금 검격 잔광, 가는 흰 열핵·halo·끝 taper·시간에 따라 변하는 빛 조각을 시도한다. 틈을 만들거나 채우는 검은 외곽·불투명 막대는 제거하며 구체 모양/빛 수치는 제작안이다.
- 제시된 다른 선택 사안들: 경쟁 연출안은 제시되지 않았다. 시전 시작과 동시에 확정선 표시까지 숨기던 이전 표현을 이번 요청으로 변경한다.
- 기존 규칙과의 관계: Player.CurrentLine은 Slash 시작에 한 번 소비하는 기존 중복 시전 방지 규칙을 유지한다. 시전 중 맵 선은 이번에 소비한 Line snapshot의 표현이며 새 사용 가능한 Line을 복원하는 것이 아니다. 실제 판정 시점·영역·피해 횟수, 취소/사망/Title 정리 규칙은 유지한다.
- 적용 상태: 시전 선 유지와 후속 검격 잔광 VFX 연결·격리22/28묶음 확인 완료. 초기 솔리드 막대/21검사는 반려 이력이며 새 GIF의 사용자 최종 미술 승인은 미확인이다. 노란색·두께·빛/표시 시간은 제작값이고 실제 결과 원본은 GAME_SPEC2.1.7을 따른다.


# 선택 사안 4 — 선 오라 전체를 포함하는 Slash 직사각 판정
- 선택: 사용자 요청(2026-11-16) — Slash 판정이 선FX의 연한 오라까지 포함하도록 넓은 직사각형으로 검사한다. 표시 자체를 늘리지 않고 같은 시작점/방향·길이를 유지한다.
- 이유: 기존 판정 범위가 보이는 선보다 좁다는 사용자 지적.
- 반영: 원본 Line.Width0.25는 유지하고 시전 시작에 DrawVfx.GetLineEffectWidth=원본 폭×Max(1,표시 배율)로 별도 HitWidth를 고정한다. 현재 표시3배에서0.75, QuerySlash 크기는(Length,HitWidth)다. 현재 시전 중 style 변경은 소급하지 않고 다음 Slash부터 적용한다.
- 유지·구분: 기존 시전선/공간참·검격 VFX와 입력/시점·피해1회·취소/사망/Title 규칙은 유지한다. 새 미술 결과가 아닌 판정 변경이며 실제29검사/소스 범위·원본 직접 실행/빌드 한계는 [GAME_SPEC2.1.7](../../GAME_SPEC.md#217-f-p07-slash-입력전용-연출한-번-판정)을 따른다.


# 선택 사안 5 — 금색탄의 입사 운동·Line 접선 반사
- 선택: 사용자 요청(2026-11-16) — Gold의 Boss 유도를 폐기하고 현재 투사체 운동 Direction을 입사 방향, 그어진 Line.Direction을 반사면 접선으로 사용한다. 탄 중심이 선 전/후 어느 쪽이어도 위치를 쓰지 않고 같은 방향으로 반사한다.
- 이유: 현재 중심 위치와 무관하게 입사 운동/선 기준으로 같은 반사가 일어나는 UX를 원한다는 사용자 요청.
- 반영: d'=Reflect(Direction.normalized,perpendicular(Line.Direction.normalized)).normalized를 즉시 저장하고 이후 고정 직진한다. ReflectionTarget은 실제 충돌 피해를 받을 Owner Boss 참조이며 추적에 사용하지 않는다. 실제 Hitbox sweep·가까운/동거리 벽 우선·Player 무해·수명/그로기/Fever1회는 유지한다.
- 이전 결정과 구분: 초기 Q12의 Boss 목표 유도를 대체한다. Slash 오라 직사각 폭0.75·기존 표시/시점/피해1회는 그대로이며 새 미술 변경이 아니다. 실제32+GoldAsset17검사·다른 suite 미실행/동시 소스 차이·원본 Play/import/빌드 한계는 [GAME_SPEC2.1.7](../../GAME_SPEC.md#217-f-p07-slash-입력전용-연출한-번-판정)을 따른다.
