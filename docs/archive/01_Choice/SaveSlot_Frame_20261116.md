# SaveSlot·설정창 공용 픽셀 프레임

주제 : SaveSlot 화면에 사용할 슬롯 한 개와 이후 설정창에도 사용할 프레임의 제작 요청
- 2026-11-16 사용자가 상단 `saveslot`·아래 세로 저장 칸 구도, 검정과 파랑·중간중간 짙고 어두운 보라 하이라이트를 지정했다.

# 선택 사안1 — 사용자 지정 색과 재사용 목적
- 선택 : 검정·파랑을 기본으로 어두운 보라 포인트가 있는 픽셀 프레임 한 개. 이후 설정창 프레임으로도 사용한다.
- 이유 : 여러 해상도와 설정창 재사용에 대응하기 위함. 색을 고른 별도 이유는 미기록
- 제시된 다른 선택 사안들 : 없음

# 제작 적용안 — 사용자 최종 미술 승인과 구분
- AI 제작값 : 256×64px·4레이어 Aseprite/PNG, 네 방향12px의9-slice, 모서리 안쪽 보라 장식. 글자는 별도 UI로 표시한다.
- 이유 : 모서리를 보존하면서 세이브 칸과 큰 창을 같은 이미지로 만들기 위함
- 결과·검증·연결 상태의 원본 : [GAME_SPEC3.3.15](../../GAME_SPEC.md#3315-saveslot설정창-공용-픽셀-프레임--2026-11-16), [편집 원본·프리뷰](../../../art/archive/ui/window-frame-r01/README.md)
- 이미지 제작 요청을 수행했으며 실제 UI 구현·설정 기능 완성이나 최종 미술 승인으로 기록하지 않는다.

# 선택 사안2 — 가로 배열과 Unity 반영
- 선택 : 2026-11-16 후속 요청에서 가로 배열도 만들고 이를 Unity에 넣어 반영하도록 요청했다. 상단`saveslot`·프레임 팔레트·세로 예시는 보존하고 실제 슬롯 화면은3개 카드를 가로로 배치한다.
- 이유 : 가로 배치·실제 적용을 원함. 가로 배열을 택한 별도 이유는 미기록
- 제작 적용값 : 동일 원본256×64를12px9-slice로144×144 카드에 사용한다.640×360 논리 좌표를 기존1920×1080 표시 안에서3배 확대한 카드 좌표와 글자 크기는 AI 배치값이다.
- 구현 범위 : `UI_Title`의 기존 IMGUI, 공용 Sprite와 씬 참조·재적용용 UIArtSetup, 관련 표시/선택 확인과 GAME_SPEC/Notion 기록. 설정 기능 자체의 새 구현은 요청 범위에 포함하지 않았다.
- 결과와 미확인 범위 : GAME_SPEC3.3.15의 이번 실제 결과를 따른다.

# 선택 사안3 — 뒤로 제거·카드 하단 확장
- 선택 : 2026-11-16 후속 요청에 따라 뒤로 버튼을 없애고 그 자리까지 포함해 가로3카드를 아래로 길게 늘린다.
- 이유 : 사용자 요청. 별도 이유는 미기록
- 적용값 : x/y/가로폭/간격은 유지하고 카드 높이144→206, 하단248→310으로 바꾼다. 새 하단310은 이전 뒤로 버튼Rect의 하단이며 프레임 원본·12px9-slice·슬롯 선택/완료 확인·취소는 유지한다.
- 적용 범위 : Unity의 슬롯 화면과 관련 프리뷰·기록만 수정한다. 대체 뒤로 키나 새 이동 방식은 추가하지 않는다.
- 실제 확인 결과 : GAME_SPEC3.3.15의 하단 확장R02를 따른다.

# 선택 사안4 — Esc 메뉴 복귀·정보 간격·굵은 글자
- 선택 : 저장 슬롯이 켜져 있을 때 Title 담당이 Esc 키 입력을 받아 슬롯을 닫고 Title 메뉴로 돌아간다. 가운데 정렬을 유지하면서 저장 정보 항목 사이에 빈 줄을 넣고, Title 버튼과 SaveSlot 글자를 더 두껍게 표시한다.
- 이유 : 슬롯 정보를 개행으로 구분하기 좋게 하려는 목적을 설명함. Esc와 글자 두께의 별도 이유는 미기록
- 구현 해석 : 현재 Title 담당은 `UI_Title`이므로 새 TitleManager를 만들지 않는다. 완료 기록 확인창이 열려 있어도 Esc는 함께 닫고 메뉴로 복귀하며 저장 덮어쓰기는 실행하지 않는다. 기존 확인창의 취소 버튼은 슬롯 목록으로 돌아간다. UI의 SelectedSlot만 비우고 SaveManager의 슬롯/Current는 유지한다.
- 범위 : 슬롯 화면 전용 InputAction 수명·입력 차단·서체 Bold·정보 줄 간격과 해당 기능 검증/기록. 뒤로 버튼 제거와 카드206높이·현재 프레임/로고/VFX·기존 저장 포맷은 유지한다. 선택3의 대체 뒤로 키 미도입은 당시 범위이며 이번 요청으로 Esc 추가가 명시적으로 승인됐다.
- 실제 결과 : GAME_SPEC3.3.15의 후속 구현·실행 결과를 따른다.
