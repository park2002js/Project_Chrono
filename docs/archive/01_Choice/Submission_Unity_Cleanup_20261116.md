# 선택 주제
주제: 제출 전 Unity 프로젝트의 비실행·디버깅 코드 제거

현재 결과: 런타임53개·Editor0, 참조 누락0과 격리6스모크를 확인했다. 후속 사용자 삭제 요청으로 당시 만든 Temp 복구 사본·검사 프로젝트·원시 로그는 제거했다. 최종 확인은 [검증 요약](../../results/Verification_Summary.json)에 남긴다.

- 2026-11-16 사용자는 제출용 Unity 프로젝트를 정리하기 전에 실제 게임 구동과 상관없는 코드와 디버깅 항목을 모두 제거하도록 요청했다
- 현재 제출용 개발 문서는 별도 경로에 이미 복사했으며, 이번 작업은 원본 `/project`의 실행 소스 정리다

# 선택 사안 1
- 선택: 실제 참조가 없는 Editor 검사·제작도구와 시험 콘텐츠를 Unity 프로젝트에서 제거
- 이유: 제출 프로젝트에 실제 게임 구동과 무관한 코드·디버깅 항목을 남기지 않기 위한 사용자 요청
- 적용: Editor 47개 C#(검사28·제작도구18·조정창1), 시험 보스/장판/레이저/원형 예고4개 C#, 시험 씬·전용 프리팹6개·미사용 씬 템플릿을 관련 meta와 함께 제거
- 보존: 실제 경비가 참조하는 원형 눈 충전 PNG는 `Assets/Art/Enemy/Warnings/GuardEyeCharge.png`로 GUID를 유지해 이동. 실제 경비 공격·AreaWarningVfx·BossStructure의 공통 전투 분기·게임 UI·데모 엔딩·오류 복구는 유지
- 제시된 다른 선택 사안들: 없음

# 선택 사안 2
- 선택: 런타임의 검사 전용 조회·관측 사건·카운터·기즈모·비활성 방향 마커와 검사 저장 경로 override를 제거
- 이유: 실제 게임의 호출·구독자가 없는 계측 코드이며 사용자 요청의 정리 대상
- 적용: 런타임16파일의 관련 API를 정리하고 Player/GameSystems 프리팹의 제거 필드·비활성 마커 참조를 함께 정리

# 선택 사안 3
- 선택: 복구 사본과 이전 검증 자료는 Unity 프로젝트 밖 로컬 `Temp/UnityRuntimeCleanup_20261116`에 보관
- 이유: 현재 미커밋 검사 파일과 기존 개발 해결 이력을 보존하면서 Unity 제출 소스에서 분리
- 현재 확인: 삭제 GUID 참조0·보존 프리팹/씬의 로컬 fileID 누락0. 같은 Unity6000.3.21f1의 독립 소스 컴파일과 격리6스모크(24프리팹/2씬·Title/새게임/실이동/공격/Title복귀)가 종료0으로 통과. Play는 사본의 SaveData.CommonPath 한 줄만 사본 안 Saves로 바꿨으며 사용자 저장 파일을 사용하지 않음
- 확인 범위: 기존 Editor Search 초기화 예외는 관찰됐으며 이번 정리로 해결한 문제가 아님. 원본 수동 Play·전체 보스 패턴 회귀·제출 빌드는 미실행. 실제 흐름·문서·다음 행동은 GAME_SPEC3.7과 STATUS를 따름
