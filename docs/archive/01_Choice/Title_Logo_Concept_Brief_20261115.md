# 선택 주제
주제 : Draw & Slash 로고 시안 제작·17번 수정·사용자 최종 원본 확정 및 작업물 정리
- 2026-11-15 사용자가 예시 Title 레퍼런스의 던그리드 로고 크기를 분석하고 이를 기준으로 계획한 로고 시안20장을 Aseprite로 제작하도록 요청함.
- 최초 제작은 원본 디자인 문서의 Draw 위 / Slash 아래 / l에 살짝 뽑힌 검이라는 구성을 이어갔으며 후속 선택으로 한 줄 구성과 최종 사용자 수정본으로 변경됨.
- 선택 사안1~11의 보존·미승인 상태와 제작 자료는 당시 이력임. 이전 아트 자료는 선택 사안12의 최종 정리 요청으로 삭제됐고, 현재 원본·확정 상태는 GAME_SPEC 3.3을 따름.

# 선택 사안 1
- 선택 : 던그리드 화면의 로고 점유 비율을 크기 비교 기준으로 사용하고 Aseprite 시안20종을 제작함.
- 이유 : 사용자가 던그리드 타이틀 로고 크기만큼 자신의 로고 크기를 정하려고 한다고 밝힘. 제작 도구와20종 수량에 대한 별도 이유는 미기록.
- 제시된 다른 선택 사안들 : 없음. Titan Souls 레퍼런스는 이번 크기 기준으로 선택하지 않음.
- 현재 사양·측정·결과 원본 : [GAME_SPEC 3.3](../../GAME_SPEC.md), 당시 아트 원본 및 비교표 자료(최종 정리 시 삭제).
- 구분 : Aseprite 제작과 크기 비교 기준은 사용자 요청임. 개별20종의 글자·장식·팔레트는 AI 제안이며 최종 시안 선택·미술 승인·Unity 적용은 당시 없었음.

# 선택 사안 2
- 선택 : 기존20종의 Draw를 더 왼쪽에, Slash를 더 오른쪽에 두고 더 가득 찬 느낌으로 수정함. 후속 첨부 이미지의 검은 곡선형 검집·밝은 손잡이·금색 가드와 끈을 검의 레퍼런스로 사용함.
- 이유 : 사용자 요청의 엇갈린 배치와 더 가득 찬 인상을 얻기 위함. 검 레퍼런스 선택의 별도 이유는 미기록.
- 제시된 다른 선택 사안들 : 없음. 기존20종은 이력으로 보존하고 V2를 별도 제작함.
- 원본 : 당시 사용자 첨부 검·V2 파일 안내 자료(최종 정리 시 삭제). 최신 사양·구현 대응 원본은 GAME_SPEC 3.3을 따름.
- 구분 : 배치·밀도 수정과 검 레퍼런스는 사용자 요청임. 구체 픽셀 위치·높이·검의 세부 생략은 제작 해석이며 V2 최종 미술 승인을 받은 것은 아님.

# 선택 사안 3
- 선택 : V2보다 Draw를 더 왼쪽·Slash를 더 오른쪽에 놓고 두 줄의 간격을 줄여 서로 맞물리게 함. 사이를 가르는 표현은 발도 중 노출된 검의 철에서 빛나는 빛으로 구성함.
- 이유 : 사용자가 두 줄을 하나의 로고처럼 꽉 차 보이게 하고, 검날에서 발생한 빛이 두 단어를 가르는 인상을 요청함.
- 제시된 다른 선택 사안들 : 없음. 이전 중앙 장식 막대를 유지하는 대신 검날에 연결된 반사광으로 수정함.
- 결과 원본 : 당시 V3 파일 안내 자료(최종 정리 시 삭제), 최신 사양은 GAME_SPEC 3.3을 따름. V1·V2는 이력으로 당시 보존했음.
- 구분 : 배치·맞물림·빛의 발생 원인은 사용자 요청임. 구체 좌표·빛의 색·강도·사선 각도는 제작 해석이며 최종 미술 승인은 당시 없었음.

# 선택 사안 4
- 선택 : 로고 전체를 한 줄로 표현하고 글자 획을 더 두껍게 하며 검의 장식을 제거함. 이전 두 줄 구성은 이번 요청으로 대체함.
- 이유 : 별도 이유 미기록. 사용자가 한 줄·더 두꺼운 표현을 다시 제작하도록 요청함.
- 제시된 다른 선택 사안들 : 없음. V1~V3를 보존하고 V4를 별도 제작함.
- 결과 원본 : 당시 V4 파일 안내 자료(최종 정리 시 삭제). 최신 사양은 GAME_SPEC 3.3을 따름.
- 구분 : 한 줄·굵은 획·검 장식 제거는 사용자 요청임. l 역할의 검 유지, 짧은 반짝임, 최대 가로156px·실제 높이46px와 검집 명암은 제작 해석이며 최종 미술 승인·시안 선택은 당시 없었음.

# 선택 사안 12
- 선택 : 사용자가 직접 수정한 최신 Aseprite를 Title 로고의 최종 원본으로 확정함. 이후 수정도 이 사용자 원본을 기준으로 하며 옛 제작 스크립트로 재생성하지 않음. `/art/title`에는 최종 Aseprite와 같은 이름의 PNG 두 파일만 남기고 나머지 Title 작업물을 정리함.
- 이유 : 최종 확정·보관 범위에 대한 별도 이유 미기록. 사용자가 현재 직접 수정본과 이후 수정 기준을 명시함.
- 제시된 다른 선택 사안들 : 없음. 이전 시안과 보조 출력을 계속 보관하는 대신 현재 원본과 PNG만 유지하도록 직접 요청함.
- 현재 원본·검사 : [GAME_SPEC 3.3](../../GAME_SPEC.md)에 최종 두 파일, 원본 해시·규격, PNG 픽셀 일치 확인과 정리 결과를 기록함.
- 구분 : 이번에는 단순 수정 기준 선택이 아니라 사용자의 최종 로고 확정임. 원본은 바이트 단위로 보존했으며 이전 R06 제작 수치를 최신 사용자 수정본에 다시 강제하지 않음. 배경·움직임·Unity 연결 완료를 뜻하지 않음.
