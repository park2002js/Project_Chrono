# 논의 중인 내용

## H01. 직접 OnDie 구독과 중계자

- 현재 제작안: Player/Boss의 상시 연결은 유지하고 전투 중 서로의 OnDie만 구독한 뒤 전투 종료 때 해제함. [P03·B01·C22](../../GAME_SPEC.md), [Q5](../../QUESTIONS.md).
- 후속 비교: 직접 연결 A / 별도 중계자를 통한 사망·전투 종료 전달 B.
- 임시 선택 이유: 직접 연결의 오버헤드가 낮을 것으로 예상하고 시간이 부족함. 예상이며 실측 결과가 아님.
- 남은 확인: 실제 호출 비용과 함께 재도전·전투 종료 때 중복 구독·해제 누락·잔류 참조를 PF04로 비교함. 현재안은 유지하고, 후속 실측에서 기능 동등성과 개선이 확인된 뒤 선택 이유를 갱신함.

## H02. 처치한 Boss의 배치

- 현재 제작안: Q5의 B, Boss 전체를 생성한 뒤 내부에서 사망 표시로 전환함. [B02·B03·S02·C05](../../GAME_SPEC.md), [Q5](../../QUESTIONS.md).
- 후속 비교: 현재 B / Q5의 A, 생성 측에서 처치 여부를 판단해 사체 표시만 준비.
- 이유: B부터 사용하고 A와 성능을 비교하겠다는 사용자 지정. B를 먼저 고른 별도 이유는 미기록.
- 남은 확인: 초기화 시간·메모리 점유·남는 참조를 실제로 비교함. 원문의 RAM 누수 방지 표현은 검증된 누수나 개선 결과를 뜻하지 않음.

## H03. 4방향에서 8방향으로의 확장

- 현재 제작안: 커서 기준 4방향·4모션. [P09·U01](../../GAME_SPEC.md), [Q9](../../QUESTIONS.md).
- 후속 검토: 8방향 몸체·모션으로 확장할지 결정함. WASD 이동 방향이나 무기 커서 방향을 4개로 제한하는 결정은 아님.
- 이유: 개발 기간 때문에 4방향을 1차 목표로 정했다는 Q9 답변. 성능 우위를 실측한 결정은 아님.
- 남은 확인: 실제 자산과 방향 전환 표현을 확인한 뒤 확장 여부를 정함. 8방향은 현재 구현 확정이나 완료가 아님.

## H04. 황금탄 반사 연출과 각도 물리

- 현재 제작안: 반사한 탄이 적 위치로 빠르게 이동하는 연출. [P08·B05](../../GAME_SPEC.md), [Q12](../../QUESTIONS.md).
- 후속 비교: 현재 연출 A / 반사각을 사용하는 물리 방식 B.
- 이유: 빠른 개발을 위해 현재안을 사용한다는 Q12 답변. 반사각을 활용하는 방식은 후속 검사 영역이며 순수 성능 비교와 구분함.
- 남은 확인: 방향·적중의 예측 가능성과 시각 전달을 비교하고 필요한 각도 규칙을 정함. 물리 방식의 성능 우위·채택은 미확정임.

## H05. 이벤트 연결과 FSM

- 현재 제작안: 연출·이벤트는 명시적 FSM 없이 이벤트 구독으로 연결함. [U07·S01·S13·C08](../../GAME_SPEC.md), [Q6](../../QUESTIONS.md).
- 후속 검토: 이벤트 연결 A / 연출·전이 관리에 필요한 명시적 FSM B.
- 이유: 이유 미기록.
- 남은 확인: 실제 진행 흐름에서 전이·중단·복구 순서를 관리하기 위해 FSM이 필요한지 검토함. 현재 상태·행동 조건을 없애는 결정도, 범용 FSM을 미리 만드는 승인도 아님.

## H06. MapManager의 추가 책임 분리

- 현재 제작안: StageManager가 생성하고 MapManager가 맵 배치·구성·상호작용을 담당함. [S02·S03](../../GAME_SPEC.md), [Q3](../../QUESTIONS.md).
- 후속 검토: 현재 책임을 유지할지, 필요해진 책임을 별도 클래스로 분리할지 판단함. 추가 클래스와 세부 분리안은 아직 정하지 않음.
- 이유: 이유 미기록.
- 남은 확인: 현재 역할의 연결을 기준으로 분리 필요성을 확인함. 원문 전체를 대규모 맵·스트리밍 구조로 확장하는 승인으로 해석하지 않음.

## H07. 일부 컷씬의 ESC skip

- 현재 제작안: 컷씬 입력 예외 없음. [P02·U07](../../GAME_SPEC.md), [Q6](../../QUESTIONS.md).
- 후속 검토: 일부 컷씬에 ESC skip을 허용할지 검토함. 대상 컷씬과 종료·복구 규칙은 미정임.
- 이유: 이유 미기록. 사용자 후속 검토 요청이며 현재 필수 구현에 추가하지 않음.

## 미지정 사항 — 보류 결정과 구별

- [B01·B04·F-B02](../../GAME_SPEC.md), [Q27](../../QUESTIONS.md): 특정 상황의 강제 우선 패턴을 둘 여지는 확정됐지만 구체 조건은 미지정임. 임의의 조건을 만들지 않음.
- GAME_SPEC C01~C21 중 이번 답변에서 후속 비교로 지정하지 않은 항목은 원래의 미실행 비교 목록에 유지함. 전부 사용자가 보류한 것으로 바꾸지 않음.
