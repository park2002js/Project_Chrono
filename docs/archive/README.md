현재 성과는 [개발 결과 종합](../results/Development_Results.md), 문서별 찾아보기는 [파일 색인](../results/File_Index.md)을 기준으로 읽는다. 현재 사양은 [GAME_SPEC](../GAME_SPEC.md), 편집 가능한 확정 자산은 [아트 카탈로그](../../art/archive/README.md)에 있다.

2026-11-16 사용자 후속 요청으로 일회성 전송·검사·지난 오류 로그·이전 진행 사본과 미확정 시안을 삭제했다. 중간 자료를 모았던 04_Process는 제거했으며, 확인된 최종 사실은 [검증 요약](../results/Verification_Summary.json)만 남긴다. 삭제·보존 확인은 [정리 결과](../results/Cleanup_Result.json)를 따른다.

## 결정 기록

확정 사양의 원본은 GAME_SPEC 한 곳이다. 선택 기록은 개발자가 선택한 것과 이유를 설명한다. 이유가 제공되지 않았다면 이유 미기록으로 남기며, AI 제안·시험 적용·사용자 확정을 구분한다. 시간 부족으로 임시 처리한 사안은 후속 검토와 구별한다.

문서·아트의 최종 정리 방식은 [정리 결정](01_Choice/Documentation_Finalization_20261116.md), 제출 소스 정리의 결과는 [Unity 정리 결정](01_Choice/Submission_Unity_Cleanup_20261116.md)을 따른다. 이전에 보존했던 복구·시험 사본은 이번 후속 삭제 요청으로 제거됐다.

## 보류와 분석 결과

[후속 비교 기록](02_Hold/Notion_Comparisons_20261115.md)은 직접 이벤트·처치 보스 생성·방향 확장·FSM·Map 책임·컷씬 skip 등의 검토 이유를 설명한다. H04의 Boss 유도 반사는 이후 Line 접선 법선의 고정 직진 반사로 변경·검증됐으므로 현재 미정으로 읽지 않는다.

유지한 분석은 실행 순서와 이동 끊김, 대시·검 정렬, 일반/Draw 카메라, 타일 경계의 밝은 줄, 대검 모션·피드백, Player 애니메이션·HUD의 구조와 실제 적용 차이다. 해결된 문제의 설명은 개발 결과에 종합했고, 원시 오류 로그를 재보관하지 않았다.

## 복구 범위

이번 작업은 별도 백업 없이 실제 삭제했다. Git에 기록된 파일은 Git으로 복원할 수 있고, 추적되지 않은 Temp·캐시·중간 작업 자료에는 별도 복구 사본이 없다. 최종 보고서·포스터·현재 게임용 자산과 편집 원본은 유지한다.
