# 기획 원문

개발자가 작성한 기획과 Notion 원문을 보존한다. 작성하지 않은 버티컬 슬라이스·범위 동결 양식은 삭제했다. 현재 규칙은 [GAME_SPEC](../GAME_SPEC.md), 제작 결과는 [개발 결과 종합](../results/Development_Results.md)을 따른다.

초기 시간 테마·자유 보스 선택·추가 콘텐츠와 현재 제출용 경비 로봇 데모의 차이는 확정 답변 및 결정 이력에서 추적한다. 초기 아이디어를 삭제하거나 현재 구현으로 재분류하지 않았다.
